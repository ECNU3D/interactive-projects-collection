# 飞机与舰艇展品设计规格

日期：2026-07-13

## 目标

把藏品大厅中现有的 X-57 电动飞机与 ASR-10 救援艇预告卡，升级为与 M4 展品同等级的完整互动内容。两件展品都必须拥有六阶段导览、十一处结构热点、程序化三维拆解、透视与原理模式、知识卡、主动朗读、静态降级、键盘/触控支持和响应式布局。

## 产品边界

- 面向少儿结构科普，解释承载、能量传递、流体、热管理和系统协作。
- 不提供制造尺寸、装配步骤、武器使用方式、救援战术或可操作工程参数。
- 所有三维几何均为项目原创的程序化教育示意，不复用受限模型，不宣称是工程级数字孪生。
- X-57 明确标注为 NASA 规划、仿真并进行部件/地面研究的 Mod IV 构型；项目在首次飞行前结束。
- ASR-10 明确标注为历史上的系泊式海上应急避难设施。互动三维船只则是受其救援叙事启发、依据公开救援艇与船舶原理组合而成的“教育型复合模型”，不是 ASR-10 原物或某艘真实船只的精确复刻。

## 共同体验

每件展品沿用“夜航博物馆”视觉语言：深墨绿空间、黄铜刻度、氧化橙结构重点、象牙白信息层级。页面结构与 M4 保持一致，让儿童在不同机械之间迁移操作经验。

共同功能：

1. 六阶段时间轴，支持前后键、点击跳转、自动演示与阶段提示。
2. 十一处可点击热点，三维选择与零件导航双向同步。
3. 拆解模式展示系统层次；透视模式淡化外壳；原理模式显示能量或流体路径。
4. 四向视角控制、缩放、已选零件聚焦和一键复原。
5. 结构知识卡包含史实依据、简化示意、观察问题与外部一手来源。
6. WebGL 不可用或 URL 带 `no-webgl=1` 时显示带可访问名称的静态 SVG。
7. 尊重 `prefers-reduced-motion`，不自动播放声音，状态变化通过实时区域播报。
8. 每件展品独立保存学习进度，不能互相覆盖。

## X-57 内容合同

正式标题：`NASA X-57 Maxwell`；副标题：`Mod IV 分布式电推进研究构型`。

六阶段：

1. 整机概览：基础飞机与电动实验平台的关系。
2. 气动骨架：细长机翼、尾翼与起落架。
3. 分布推进：两台翼尖巡航电机和十二台高升力电机。
4. 储能供电：两套电池与 A/B 电力通道。
5. 功率变换：控制器把直流电转换成电机需要的电流形式。
6. 感知散热：驾驶舱监测、冷却风路与安全研究。

十一部件：基础机身与座舱、高展弦比机翼、尾翼与操纵面、起落架、翼尖巡航电机、十二台高升力电机、锂离子电池组、A/B 电力通道、逆变器与控制器、驾驶舱监测系统、被动冷却路径。

准确性约束：

- 不写“成功首飞”或“完成 Mod IV 飞行验证”。
- “14 台电机”只描述 Mod IV 设计，不暗示它们曾在同一架飞机上完成联合飞行。
- 设计目标、风洞结果、仿真结果和部件效率不能改写成整机实飞结论。
- “零排放”只可解释为飞行中没有燃油燃烧产生的直接排放。

## ASR-10 内容合同

正式标题：`海上救援结构实验室`；副标题：`ASR-10 启发的教学复合模型`。

六阶段：

1. 整艇概览：船体怎样排水并提供工作平台。
2. 船体骨架：外壳、甲板、隔舱与上层建筑。
3. 内部空间：浮力分舱、泵舱和救援工作区。
4. 动力传递：发动机、传动轴和螺旋桨的高层关系。
5. 航向控制：舵面、驾驶舱与观察/导航信息。
6. 系统协作：排水、救援甲板和结构稳定的共同作用。

十一部件：船体外壳、甲板与上层建筑、水密/浮力舱、双发动机模块、传动轴路径、螺旋桨示意、舵与转向、泵舱/舱底排水、驾驶舱与观察桅杆、救援工作甲板、人员安置空间。

准确性约束：

- 明确说明历史 ASR-10 是系泊海上的应急避难设施，依靠无线电呼叫快速救援船，不把它描述成机动救援艇。
- 不声称教学复合船对应某个真实艇型、尺度、速度或机构布局。
- 只说明通用的船体、浮力、分舱、推进、转向和救援空间原理。
- 不给出救援程序、驾驶方法、设备操作或可用于实际船舶设计的参数。
- 螺旋桨、舵、泵路、驾驶台和隔舱均标注为现代救援艇通用的原理化示意，并明确它们不是历史 ASR-10 原物结构。

## 信息架构与工程方向

- 新增展品注册表，把标题、类别、步骤、部件、静态示意类型和模型声明统一交给探索页。
- `ExplorerPage` 接收 `exhibitId`，不复制三套页面；M4 的默认行为保持兼容。
- 通用场景接口承载状态、选择、聚焦和相机命令；每种机械保留独立的程序化模型。
- 类型系统覆盖三件展品的部件 ID 与来源 ID；来源清单只加入实际使用的一手资料。
- 状态仍为六阶段，但本地存储键按展品区分。

## 验收标准

- 三张大厅卡全部可进入正确路由；非法路由仍回到大厅。
- 每件展品均恰有六阶段和十一部件，内容可追溯且带教育性重建声明。
- 三种模式、自动演示、热点选择、聚焦、复原、进度保存和静态降级在三展品上行为一致。
- Vitest 全量通过，新增内容/路由/状态/模型契约测试先红后绿。
- Playwright 覆盖三件展品的关键路径，并在 1440×900、1024×768、390×844 检查布局。
- 真实截图中无截断、遮挡、低对比度、空白舞台或明显几何穿插；浏览器控制台无应用错误。
- 生产构建通过，既有 M4 行为不回归。
