# 枪械机械循环实验室设计规格

日期：2026-07-13

## 目标

在现有机械结构科普应用中新增四件完整枪械展品，让少儿用户通过程序化三维剖面观察不同枪械机构如何完成能量传递、往复运动、供弹、抽抛壳与复位。新增展品包括 M1903 Springfield、M1911A1、M1 Garand 与标准型 HK MP5，分别代表手动旋转后拉枪机、枪管短后坐、导气操作杆与滚柱延迟反冲四种机械原理。

每件展品必须达到现有坦克、飞机和舰艇的完整标准：六阶段导览、十一处结构热点、拆解/透视/原理三模式、可聚焦程序化三维模型、知识卡、主动朗读、独立进度、静态降级、键盘/触控支持和响应式布局。

## 产品与安全边界

- 面向约 8–14 岁儿童及亲子用户，解释机械因果关系与历史工程差异，不鼓励武器使用。
- “发射”只表现为透明青白色惰性示意弹、抽象橙色能量脉冲和慢动作机械循环，不表现真实弹药内部结构。
- 不提供制造尺寸、公差、材料、加工、装配、拆解顺序、排障、改装、瞄准、射击姿势、战术、膛压、弹速、射程、穿透或杀伤比较。
- 输入与击发只用不可拆分的“输入联动模块”和能量光效表示，不重建可制造的扳机、阻铁或击针接触几何。
- 无真实枪声、枪口焰、目标、命中、人体、破坏效果、连发演示或射速比较；模型始终以博物馆侧视/剖面视角呈现，不朝向观众。
- 原理动画默认关闭，每次只播放一个机械循环，播放结束停在完成状态，不自动重播。
- 拆解视图是教学分层，不对应真实拆装顺序、紧固件或装配路径；界面和知识卡明确标注“非拆装说明”。
- 所有三维几何均为项目原创程序化教育示意，不复用馆藏或厂商受限素材，不宣称是工程图或数字孪生。

## 信息架构

藏品大厅由三张大型机械卡扩展为两个内容分区：

1. `陆海空大型机械`：M4 中型坦克、NASA X-57 Maxwell、海上救援结构实验室。
2. `发射循环实验室`：M1903 Springfield、M1911A1、M1 Garand、HK MP5。

大厅不再写死 `COLLECTION 01—03` 与三张不对称卡片布局。桌面端以分组标题和可扩展卡片网格呈现七件藏品；平板与手机保持自然单列或双列流动。枪械卡的视觉仍使用深墨绿、黄铜、氧化橙和象牙白，不采用准星、战斗 HUD、击杀、等级或弹药计数器。

## 共同学习体验

每件枪械沿用以下六阶段结构，具体文案按机构差异调整：

1. 整体观察：识别外部承载结构和主要机械分区。
2. 外壳与支撑：观察枪管、机匣/套筒、握持或支撑结构的相对关系。
3. 内部剖面：淡化外壳，找到闭锁、复进、供弹与抽抛壳模块。
4. 能量传递：追踪抽象能量脉冲从输入模块到往复结构的因果路径。
5. 机械循环：以确定性阶段播放惰性示意弹、枪机/套筒、复进结构与抽抛壳联动。
6. 系统复位：观察机构如何回到准备状态，并比较该机构与其他展品的差异。

共同功能：

- 六阶段时间轴支持前后键、点击跳转、导览提示与自动演示。
- 十一处热点支持三维点选、零件导航、聚焦和知识卡同步。
- 拆解模式按教学层次展开；透视模式淡化外壳并允许点击内部；原理模式显示能量与机械循环。
- 机械循环提供“播放一次机械循环”“暂停机械循环”“上一循环阶段”“下一循环阶段”“复原循环”按钮。
- 循环状态通过可访问文本播报，例如“循环阶段 4 / 6：往复结构后移，复进结构储存能量”。
- `prefers-reduced-motion` 下禁用连续播放，保留逐阶段查看；页面不自动播放声音。
- WebGL 不可用或 URL 带 `no-webgl=1` 时，使用随主导览阶段改变的静态剖面 SVG 和完整文字卡。
- 每件展品独立保存主导览进度，不得互相覆盖。

## 视觉语义

- 深青：静止外壳与承载结构。
- 黄铜：当前运动或当前选中的机械部件。
- 氧化橙透明脉冲：能量传递方向。
- 青白斜纹体：惰性示意弹与空壳替身。
- 虚线轮廓：下一循环阶段的位置提示。
- 颜色同时配合编号、名称和轮廓，不把颜色作为唯一信息载体。

## M1903 Springfield 内容合同

正式标题：`M1903 Springfield`；副标题：`手动旋转后拉枪机教学剖面`。

构型边界：以标准 M1903 的总体外形和 NPS 史料为依据，不混合 M1903A3、早期杆式刺刀或其他年代特征；模型为教学性重建。

十一部件：木质支撑外形、机匣外壳、枪管与膛室示意、旋转枪机体、闭锁凸笋概念、枪机柄、复进/击发能量模块、内部供弹区、抽壳与抛壳路径、惰性示意弹路径、机械状态指示。

循环重点：能量输入和惰性弹移动后，枪机保持闭合；用户通过循环阶段观察枪机柄抬起、枪机旋转退出闭锁、后移抽抛壳、前移供弹和重新闭锁。该过程仅为顺序动画，不是操作或拆装指导。

## M1911A1 内容合同

正式标题：`M1911A1`；副标题：`枪管短后坐与倾斜闭锁教学剖面`。

构型边界：参考 Smithsonian 约 1944 年 Remington Rand M1911A1 的历史记录，避免把早期 M1911 与现代衍生型号的外形混合；模型不复用馆藏图片。

十一部件：握把与框架外形、套筒外壳、枪管与膛室示意、短后坐联动组、倾斜闭锁概念、复进簧模块、输入联动模块、供弹容器示意、抽壳与抛壳路径、惰性示意弹路径、机械状态指示。

循环重点：惰性弹移动后，枪管与套筒先共同短距离后移；枪管尾部随后下降，套筒继续后移并完成抽抛壳示意；复进结构推动套筒前移、供弹并恢复闭锁。单次释放关系只用高层状态说明，不展示可制造接触几何。

## M1 Garand 内容合同

正式标题：`M1 Garand`；副标题：`导气操作杆与旋转枪机教学剖面`。

构型边界：采用 1940 年后常见导气孔式 M1 的高层布局，不误画成早期集气罩式；供弹区表现为八发整体弹夹概念，不改成可拆卸盒式弹匣。

十一部件：木质支撑外形、机匣外壳、枪管与膛室示意、导气路径、长操作杆/活塞概念、旋转枪机、复进结构、整体弹夹供弹区、抽壳与抛壳路径、惰性示意弹路径、机械状态指示。

循环重点：惰性弹经过靠近枪管前部的抽象取能位置后，能量脉冲进入导气路径；操作杆后移并带动枪机旋转解锁，随后完成抽抛壳、前移供弹和重新闭锁。末发弹夹状态只作为历史结构提示，不演示装填或操作步骤。

## HK MP5 内容合同

正式标题：`HK MP5`；副标题：`滚柱延迟反冲教学剖面`。

构型边界：采用标准型 MP5 教学外形，不混合 MP5K、MP5SD 或不同枪托变体；只展示单发机械循环，不表现连发与射速。

十一部件：机匣外壳、枪管与膛室示意、枪机头、后部枪机组件、滚柱延迟概念、斜面传力概念、复进结构、供弹容器示意、抽壳与抛壳路径、惰性示意弹路径、机械状态指示。

循环重点：惰性弹移动后，枪机头承受抽象后向作用；滚柱沿概念斜面向内移动，使前后组件产生相对延迟，再完成整体后移、抽抛壳、复进供弹与滚柱复位。知识卡不得给出滚柱角度、传动比、尺寸或加工关系。

## 工程架构

### 内容层

- 在 `content/types.ts` 增加 `firearm` 类别、四个展品 ID、共享枪械部件 ID 和实际使用的来源 ID。
- 每件枪械拥有独立内容定义；共享部件 ID 可以在不同展品中使用不同中文名称和知识卡。
- `exhibits.ts` 与 `catalog.ts` 注册七件可用藏品；来源清单只包含实际引用的一手或权威页面。

### 三维层

- 新增共享 `FirearmScene`、`FirearmModel` 与 `FirearmPart`，通过 `exhibitId` 选择四套构型配置。
- `ExplorerPage` 把 `exhibitId` 传给通用场景接口；四个枪械路由共用一个动态导入块。
- 新增 `firearmCycle.ts` 纯函数采样器，根据构型、循环阶段和时间输出枪机/套筒、闭锁、复进、供弹、抽抛壳、惰性弹与能量脉冲状态。
- 循环引擎与 Three.js 对象分离，保证可测试、可暂停、可逐阶段和可在减少动态模式下确定性呈现。
- 抽取飞机与舰艇重复的部件透明、选中、悬停、射线禁用和 `invalidate()` 行为为通用机械部件组件；不进行与本功能无关的重构。

### 状态与数据流

`选择枪械 → 读取展品与构型 → 创建主导览状态 → 进入原理模式 → 用户播放或逐阶段推进循环 → 纯函数计算当前机械样本 → 三维几何与可访问状态同步 → 单次循环结束并保持`

主导览的方向键与机械循环按钮相互独立。主导览仍为六阶段；循环阶段只在原理模式中存在，不写入跨会话进度，复原模型时回到循环初始状态。

### 静态降级与错误处理

- 静态枪械 SVG 根据当前展品和主导览阶段改变剖面高亮，不伪装成完整动画。
- `SceneBoundary` 必须接收当前展品的静态示意类型，不得在枪械错误时显示 M4 坦克图。
- 场景导入失败时提供重试、静态继续学习和返回大厅；循环状态异常时复原到初始阶段，不影响知识卡。
- 非法展品路由返回大厅；损坏的本地进度恢复到第一阶段。

## 响应式与无障碍

- 桌面保留左侧导航、中央舞台、右侧知识卡和底部时间轴；循环控制位于舞台内，不遮挡模型热点。
- 平板压缩循环说明与知识卡宽度；手机把循环按钮分成两行，所有可见触控目标不小于 44 × 44 CSS 像素。
- Canvas 通过 `aria-describedby` 关联当前循环阶段；循环状态使用 `aria-live="polite"`，只在阶段变化时播报。
- 播放、暂停、逐阶段和复原均有文字标签；不要求拖拽才能完成循环。
- 暂停时场景必须停止持续渲染；减少动态时逐阶段切换立即完成，不使用持续缓动。

## 性能约束

- 大厅、静态路径和非枪械展品不会下载枪械 Three.js 代码。
- 四个枪械路由共用一个枪械场景懒加载块，不复制 Three.js 依赖。
- 只有可见且正在播放的原理循环使用持续渲染；其余状态使用按需帧循环。
- 复用几何与材质，限制透明层和实时阴影；移动端沿用现有 DPR 与阴影质量分级。
- 暂停后相隔至少 250ms 的两张 Canvas 截图必须完全一致。

## 测试与验收

### 单元与组件测试

- 内容合同：七件展品全部可用；每件恰有六阶段、十一热点、来源和重建声明。
- 安全合同：枪械文案包含惰性示意与非拆装声明，不包含被禁止的参数、操作或杀伤描述。
- 路由与存储：四个新路由可直接进入；非法近似路由被拒绝；七件展品进度彼此隔离。
- 循环纯函数：四种构型在指定阶段产生不同的枪机/套筒、闭锁、导气/延迟、惰性弹和抽抛壳状态；复原值确定。
- 场景合同：四件枪械共用一个加载器，构型覆盖全部十一热点，焦点位置与外壳射线规则完整。
- UI：循环按钮状态、可访问播报、减少动态逐阶段路径和静态降级正确。

### Playwright 真实浏览器流程

对四件枪械分别验证：

1. 从分组大厅进入正确路由，标题、六阶段和十一热点可见。
2. 真实 WebGL 画布可点选热点并显示对应知识卡。
3. 拆解、透视、聚焦前后 Canvas 像素发生变化。
4. 原理模式播放一次完整循环，阶段递增且连续帧像素不同；结束后不自动重播。
5. 暂停后连续截图完全稳定；复原回到循环第一阶段。
6. 减少动态模式禁用连续播放，逐阶段按钮仍可完成循环。
7. 刷新后主导览进度恢复；复原模型后返回第一阶段；不同枪械进度不互相覆盖。
8. `no-webgl=1` 下无 Canvas，静态剖面、六阶段和全部知识卡仍可访问。
9. 控制台错误、页面错误和失败 HTTP 响应为零。

### 视觉验收

- 截图覆盖 1440×900、1024×768、390×844。
- 检查七卡大厅的分组层级、模型占比、循环控件、知识卡可读性、文字溢出、遮挡、横向滚动和 44px 触控目标。
- 检查四种枪械拆解与循环关键帧，确保惰性弹、外壳、运动件和路径之间无明显穿插，侧视方向不朝向观众。
- 检查深色背景下正文、弱化文字、焦点环、黄铜运动件和青白惰性弹的对比度。
- 最终视觉验收以真实浏览器截图和交互结果为依据，不以代码存在代替完成度。

## 完成定义

只有在以下条件全部满足时，本功能才算完成：

- 七件藏品均可从大厅和直接路由进入，既有三件展品无回归。
- 四件枪械均具备六阶段、十一热点、三种模式、一次性机械循环、逐阶段路径、知识卡、独立进度与静态降级。
- 全量 Vitest、TypeScript、Vite 生产构建与 Playwright 通过。
- 桌面、平板和手机截图经过实际视觉检查，无高/中等级布局、交互或可读性问题。
- 浏览器控制台、页面错误和失败网络请求为零。
- 独立规格审查与代码质量审查通过，全部重要问题已修复。
- 功能分支合并回 `main`，工作树清理完成。
