# 《紅樓夢》· 入府遊 — 設計文檔

2026-08-08

## 一、目標

用 Three.js 復原《紅樓夢》中寧國府、榮國府與大觀園的三維可漫遊場景。時間錨定 **第二十三回之後、第五十四回之前**——元春省親已畢，大觀園建成，姊妹已入園居住的鼎盛時期。玩家第一人稱行走其中，行至看點自動觸發語音講解，關鍵房屋可入內參觀，府中 NPC 自由活動，右上角小地圖實時顯示所在院落。

## 二、技術棧

- Three.js ES Module + `importmap`，無構建步驟
- 全部貼圖 Canvas 程序化生成，零外部圖片資源
- 音頻由 MiniMax API 生成（`/v1/t2a_v2` 語音、`/v1/music_generation` 配樂）
- 本地運行：`python3 -m http.server 8430`

## 四、考據依據（優先級由高到低）

1. **原著文本**——方位與路線描寫
   - 第三回 黛玉進府：西角門 → 一射之地 → 垂花門 → 抄手遊廊 → 穿堂（紫檀架子大理石大插屏）→ 小小三間廳 → 正房大院（正面五間上房、穿山遊廊廂房）
   - 第十六回 建園：「先令匠人拆寧府會芳園牆垣樓閣，直接入榮府東大院中……當日寧榮二宅，雖有一小巷界斷不通，然這小巷亦係私地，並非官道，故可以連屬。會芳園本是從北拐角牆下引來一股活水，今亦無煩再引。」**——本項目採用的「打通後」狀態即出自此段**
   - 第十七回 試才題對額：園門 → 翠嶂 → 曲徑通幽 → 沁芳亭橋 → 瀟湘館 → 稻香村 → 蘅蕪苑 → 蓼汀花漵 → 省親別墅正殿 → 怡紅院（順時針）
   - 第十七回 沁芳閘賈珍語：「原從那閘起流至那洞口，從東北山坳裡引到那村莊裡，又開一道岔口，引至西南上，共總流到這裡」——定水系走向
2. **學術考證平面圖**——楊乃濟、戴志昂、徐建平
3. **清代王公府邸規制**——寧榮二府「中路有大廳、內廳、正堂、後罩房四重主要建築」，「實際和清代貝勒府的規制相同」；中路五道禮儀之門：大門、儀門、內三門、內儀門、內塞門；大門三間、正堂五間

## 五、模塊劃分

| 文件 | 職責 |
|---|---|
| `js/palette.js` | 色譜 |
| `js/textures.js` | 程序化貼圖（瓦壟、彩畫、櫺心、墁地、粉牆、太湖石⋯⋯） |
| `js/materials.js` | 材質通道、水面、天空、煙 |
| `js/geo.js` | GeoBuilder：多通道合併 + 三向映射 UV + 按院落分塊 |
| `js/parts.js` | 構件庫：台基、柱、枋、斗栱、屋頂、槅扇、欄杆、垂花門、遊廊、月洞門、影壁、匾額 |
| `js/compound.js` | 院落生成器：數據 → 幾何 |
| `js/data/*.js` | 40+ 院落的聲明式數據 |
| `js/garden.js` | 山石、沁芳水系、橋閘、花木 |
| `js/interior.js` | 12 處可入室內 |
| `js/people.js` | 環境 NPC |
| `js/figures.js` | 主要人物 |
| `js/pois.js` | 講解觸發點 |
| `js/map.js` | 小地圖 + 全屏全圖 + 神遊 |
| `js/audio.js` | BGM、環境聲、講解與字幕 |
| `js/controls.js` | 漫遊控制、碰撞、憑虛御風 |
| `js/layout.js` | 世界常量、碰撞盒、地面高度 |
| `js/main.js` | 入口、分階段加載、主循環 |

**核心決策：40+ 院落走數據驅動生成器**，而非逐個手寫 builder。院落數據描述「院牆、門、殿宇（面闊／進深／屋頂形制／等級／朝向）、遊廊、鋪地、花木、室內 id」，由 `compound.js` 統一生成幾何。

## 六、建築等級（決定屋頂／彩畫／台基／瓦色）

| 等 | 實例 | 屋頂 | 彩畫 | 台基 | 瓦 |
|---|---|---|---|---|---|
| 一 | 省親別墅正殿、玉石牌坊 | 廡殿／歇山 | 和璽 | 須彌座 | 綠琉璃剪邊 |
| 二 | 榮禧堂、二府大廳正堂、賈母院 | 歇山／硬山 | 旋子 | 台明 | 筒瓦、吻獸、仙人走獸 |
| 三 | 園中軒館、遊廊、亭榭 | 卷棚／懸山／攢尖 | 蘇式 | 石階 | 灰筒瓦 |
| 四 | 群房下人房、稻香村 | 硬山／茅茨 | 無 | 素土 | 板瓦／稻莖 |

屋頂幾何統一由「舉折 + 翼角起翹」參數化曲面生成：從檐口 `s=0` 到脊 `s=1`，升高 `y = H·s^1.5`（近檐平緩、近脊陡峻）；一、二、三等的歇山／廡殿／攢尖在角部疊加起翹與出翹，四等硬山不起翹。

## 九、NPC

- **環境 NPC ~160 位**：丫鬟、婆子、小廝、管事、匠人、小道士、更夫。每位綁定所屬院落 + 沿遊廊甬路的巡行路線。InstancedMesh 按服色分組。
- **主要人物 18 位**：賈母、王夫人、鳳姐、寶玉、黛玉、寶釵、探春、迎春、惜春、李紈、妙玉、湘雲、平兒、襲人、晴雯、鴛鴦、賈政、賈赦、賈珍尤氏。走近顯示名牌並觸發該人物的經典故事講解。
- ⚠️ 秦可卿卒於第十三回，早於省親，故**不作活動 NPC**；其臥房作為遺構配第十三回講解。

## 十、地圖

右上角常駐小地圖（由布局數據自動生成的工筆平面圖 + 朱色方向箭頭 + 當前院落題名）；`M` 展開全屏全圖，已遊處朱點、未遊處墨點，點擊景點可「神遊」直達。`F` 切換憑虛御風鳥瞰。

## 十一、音頻

`audio/gen_audio.py` 調 MiniMax：講解約 30 處地點 + 12 位人物，每段 300–500 字；BGM 3 首（府邸莊重／園中清雅／夜色）；環境聲（水聲、竹風、鳥鳴）由 WebAudio 程序化生成。

## 十二、性能

院落為裁剪單元（距離 + 視錐）；每院按材質通道合併幾何；室內延遲構建；NPC 實例化。目標 draw call < 120、視野內三角面 < 1.5M。

## 十三、自檢

`?shot=` 調試機位逐院截圖驗收；碰撞不穿牆；POI 觸發與音頻播放；地圖定位正確；性能日誌；分階段加載無異常。

## 實作結果（2026-08-08 完成）

規模比設計時預估的略大：**65 個院落定義／62 個裁剪單元、544k 三角面、850k 頂點、475 個碰撞盒、247 個台基平台、75 個分區**。幾何生成合計 **約 250ms**（`node tools/bench.mjs`）。

與設計的偏差：

1. **地圖代步**：設計裡沒有的「神遊」——全圖上點景點可直達。大觀園按周長三里半推算縱深近 640m，實走過遠，故補了這條。
2. **配樂三軌**：除府邸／園中兩軌外，另生成夜色一軌，用於凸碧山莊·凹晶溪館一帶（中秋賞月處）。
3. **自檢改為腳本化**：`tools/selfcheck.mjs` 用最小 DOM/Canvas 樁在 Node 裡把世界造一遍，八類檢查全自動；比逐院截圖可靠得多，也快得多（秒級）。截圖驗收保留為 `tools/grab.sh`，改用 `canvas.toDataURL()` 讀回畫面——無頭 Chrome 的 `--screenshot` 常在異步興造完成前就拍了。
4. **色彩管線**：實作中發現「貼圖 × 頂點色」會把顏色乘暗兩次。改為細節貼圖歸一成近白灰度、色調全由頂點色承擔，提亮係數由貼圖實測線性均值反推（`texBoost`）。
5. **簡化**：斗栱間距由 1.5m 放寬到 2.8m 並省去「升」，門釘由 7×6 減為 5×6，竹林單叢上限 26 竿——都是為控面數，形制等級關係未動。

後續修掉的幾個缺陷（由用戶回饋與新增的可達性／NPC／水系自檢發現）：**沁芳溪西支從秋爽齋正房底下穿過、又貼著稻香村東牆走**，四座橋因而架進了院子裡（翠煙橋入秋爽齋、稻香村板橋入稻香村、藕香榭竹橋入綴錦樓、蜂腰橋入怡紅院），綴錦閣則整座泡在水裡；**台基中心的前後偏移方向寫反**，前廊柱整排落在台基之外懸空站在踏跺上；**踏跺斜坡的高低兩端寫反**，檐前變成一道 0.85m 的坎，二等以上建築全都上不去；**橋面高程無條件蓋過台基**，蓼汀橋在省親別墅正殿腳下挖出一個踏空的坑；**瀟湘館南門泡在沁芳溪裡**；**環境 NPC 只判水不判碰撞盒**，成片穿牆穿台基；**大門門扇過高遮住匾額**、且繞自身中心旋轉時翻進門洞。

早期修掉的幾個實質缺陷（均由截圖或自檢發現）：園地高程網格與水面的三角形繞序朝下（整片地與水不可見）、荷葉沉在水面之下、出生點朝向反了 180°、大門退進府牆 9m、槅扇「實牆」型硬編碼成粉牆而非隨牆色、儀門類建築沒有可穿行的門洞、進屋提示只在「最近的室內換了一處」時才更新。
