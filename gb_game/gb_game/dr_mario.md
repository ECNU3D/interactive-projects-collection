【Game Boy 复古风格总纲 —— 以下所有要求为硬性约束】

1. 交付形式：单个 .html 文件，零外部依赖（不引用任何 CDN、字体、图片文件），
   双击即可在浏览器中运行。所有 CSS 和 JavaScript 内联。

2. 画面规格：
   - 使用 <canvas>，逻辑分辨率固定为 160×144（原版 Game Boy 屏幕分辨率）。
   - 用 CSS 把画布整数倍放大（自动选择适合窗口的 3~5 倍），并设置
     image-rendering: pixelated，保证像素锐利不发虚。
   - 整个页面只允许使用 Game Boy DMG 的 4 色绿色调色板：
     #0f380f（最深）、#306230（深）、#8bac0f（浅）、#9bbc0f（最浅/背景）。
   - 画布外的网页背景做成 Game Boy 机身的灰紫色 (#c4bebb)，画布嵌在中间，
     四周留出圆角边框，像在看真机屏幕。

3. 操作映射（统一全部游戏）：
   - 方向键 = 十字键；Z = B 键；X = A 键；Enter = Start；Shift = Select。
   - 页面底部用一行小字常驻显示本游戏的按键说明。
   - 同时支持触屏：屏幕下方渲染半透明的虚拟十字键和 A/B 按钮。

4. 字体与文字：所有游戏内文字用 canvas 手绘的 8×8 像素字体或等宽字体模拟，
   禁止使用现代无衬线字体直接渲染在画布上。

5. 音效：用 Web Audio API 合成 8-bit 芯片音效（方波+噪声通道），
   不加载任何音频文件。首次按键后才初始化 AudioContext（浏览器自动播放限制）。

6. 游戏结构：必须有三个状态——标题画面（按 Start 开始）、游戏中、
   Game Over 画面（显示得分和 "PRESS START"）。标题画面要有闪烁的
   "PRESS START" 文字，这是灵魂。

7. 手感：用 requestAnimationFrame 主循环，固定 60fps 逻辑帧；
   按键要处理"按住连发"和"单次触发"两种情况，不允许出现输入丢帧。

请为我实现 GB 版《马里奥医生》(Dr. Mario) 复刻，单文件 HTML5/JS：

玩法规则：
- 8 列 × 16 行的药瓶场地。开局在场地下半部随机分布若干"病毒"
 （GB 是灰阶，这里用 4 色绿调中的 3 种深浅区分 3 类病毒，每类病毒有独特的
  2×2 像素表情动画）。
- 从瓶口落下双色胶囊（两半各为 3 色之一），左右移动、Z/X 旋转。
- 同色 4 连（横或竖，胶囊半粒和病毒都算）即消除；胶囊剩下的半粒受重力下落，
  可触发连锁消除。
- 消灭全部病毒过关；胶囊堆到瓶口 Game Over。
- 可在标题画面选择初始病毒数量（LEVEL 0~9）和下落速度（LOW/MED/HI）——原版就有这个选单。
- 右侧显示：NEXT 胶囊、剩余病毒数 VIRUS、SCORE。

画面与音效：
- 三只病毒在场地角落有个小放大镜圆窗，各自蹦跳做鬼脸，被消灭一类就少一只——
  这是 Dr. Mario 的灵魂细节，必须做。
- 消除音效连锁时音高逐级上升；过关播放一段 8 小节的胜利小旋律。
