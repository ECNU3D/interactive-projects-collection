# 《山河岁月》——中国近代史画卷互动游戏 设计文档

- 日期：2026-07-12
- 状态：已获用户批准（方案A：画卷主轴 + 沉浸抉择）
- 需求来源：`需求.md`

## 1. 项目概述

一个中国近代史科普 + 游戏类型的网页 App，时间跨度 **1839（虎门销烟前夜）→ 1949（新中国成立）→ 1978（改革开放）**。玩家沿一条横向展开的历史画卷逐节点推进历史进程，在关键节点做出抉择、获得得分，同时学习史实与人物知识。

核心原则：

1. **历史不可改变**：玩家选错不改变剧情走向；立即展示正确答案与"为什么历史选择了这条路"的解析，剧情严格按史实推进。
2. **史实第一**：所有时间、事件、人物、因果先落盘为本地数据文件并逐条核对，数据可后续增改；先有数据，后有 App。
3. **美感与底蕴**：宣纸水墨视觉、画卷式交互、沉浸式全景抉择、庄重的红色主题终章。

## 2. 已确认的关键决策

| 决策 | 结论 |
|------|------|
| 内容规模 | 极详尽版：15 章、70+ 历史节点、25+ 关键抉择点 |
| 图片策略 | 混合：抉择点全景图用 gpt-image-bridge 生成（25+ 张）；人物头像/事件照片优先维基百科等公有领域老照片，下载到本地并记录来源；缺失的用 AI 生成补足 |
| 运行方式 | 纯静态网页：数据打包为 `.js` 文件，双击 `index.html` 即玩（file:// 协议下可运行），无构建、无外部网络依赖 |
| 整体结构 | 方案A：画卷主轴 + 沉浸抉择 + 人物星图，吸收关卡式的节点解锁与进度要素 |

## 3. 章节结构（15 章）

1. 鸦片战争与国门洞开（1839–1842，含第二次鸦片战争 1856–1860）
2. 太平天国运动（1851–1864）
3. 洋务运动：自强与求富（1861–1895）
4. 甲午战争与瓜分狂潮（1894–1898）
5. 戊戌变法（1898）
6. 义和团、庚子国变与清末新政（1899–1911）
7. 辛亥革命（1911–1912）
8. 民初乱局与新文化运动（1912–1919）
9. 五四运动与中国共产党诞生（1919–1921）
10. 国民革命与大革命（1924–1927）
11. 土地革命与红军长征（1927–1936）
12. 抗日战争（1931–1945）
13. 解放战争（1945–1949）
14. 新中国成立与社会主义建设（1949–1956）
15. 曲折探索与改革开放（1956–1978）

每章含 4–6 个历史节点；其中 1–3 个是关键抉择点。全程合计 ≥70 节点、≥25 抉择点。

## 5. 数据模型

### chapters.js
`{ id, title, subtitle, startYear, endYear, theme(时代色调), intro(章引言 100–200字) }`

### events.js（历史节点）
`{ id, chapterId, date(精确到年月日或年月), title, place, summary(150–300字正文), significance(历史意义 80–150字), extra(史海钩沉小知识 50–120字), image(可选，事件照片路径), personIds[](关联人物), choiceId(可选，该节点是抉择点时指向 choices) }`

### choices.js（关键抉择点）
`{ id, eventId, scene(情境描述，第二人称代入，120–250字), panorama(全景图路径), question, options: [{ text, correct, feedback(为什么对/错，100–200字) }], historyNote(历史真实走向说明) }`

抉择点设计原则：站在历史当事人的视角提问（如"你是1898年的光绪帝，变法诏书如何推行？"），正确答案 = 历史上实际发生且被历史证明的方向；解析讲清楚"历史为什么这样走"。

### persons.js（人物知识图谱）
`{ id, name, courtesy(字号，可选), birth, death, role(身份一句话), bio(150–300字小传), image(照片路径), chapterIds[](登场章节) }`
关系边：`{ source, target, relation(师承/同盟/对立/影响/亲属), note }`

## 6. 玩法与计分

- **推进**：节点按顺序解锁；读完当前节点（点击"继续"）亮起下一节点；抉择点必须作答后才能继续。
- **计分**：
  - 首答即对 +100；
  - 答错后阅读解析并点击"我明白了" +20（明理分）；
  - 阅读"史海钩沉" +10（探索分）；
  - 连续答对有连击加成（×1.1/×1.2/×1.3，封顶）。
- **章节评级**：每章结束按该章得分率给"史识评级"：甲（≥85%）/ 乙（≥60%）/ 丙（<60%），可重玩章节刷新评级。
- **称号**：按总分与答对率解锁——"初识风云""洞察者""史家""民族脊梁"。
- **存档**：进度、分数、评级、已点亮人物存 localStorage；提供"重新开始"。

## 7. 界面与美术

- **画卷主界面**：横向滚动长卷；宣纸底纹 + 水墨晕染；章节题名竖排 + 朱砂印章；时间轴如江河贯穿，节点为珠串（未解锁灰暗、当前鎏金、已完成朱红）。
- **时代色调**：随章节渐变——晚清昏黄 → 辛亥灰蓝 → 建党觉醒的渐亮 → 抗战肃穆 → 解放炽红 → 建国明亮 → 改革开放晨曦。
- **节点卡片**：图文结合（事件照片 + 正文 + 意义 + 史海钩沉 + 关联人物头像，点头像跳人物星图）。
- **沉浸抉择模式**：全屏全景图 + 情境旁白渐入 + 选项卡片；答题后反馈动效（对：金光印章"史笔如铁"；错：墨色晕开 + 解析卷轴）。
- **人物星图**：d3 力导向图；人物随剧情推进点亮；点选看小传与关系；关系边按类型着色。
- **终章卷轴**：1949 开国大典高潮节点后继续至 1978；终章回顾玩家全程抉择与得分，庄重的红色主题：致敬先辈——"无数先辈的牺牲与正确抉择，才换来新中国与今日中国"。

## 8. 音效（Web Audio 合成，无外部音频文件）

- 环境：古琴泛音式微弱底噪（可选开启）。
- 交互：翻页沙沙声、节点解锁清音、答对编钟声、答错沉闷鼓音、终章庄重和声。
- 全局静音开关，状态存 localStorage。

## 9. 图片素材流程

1. **全景图（25+）**：gpt-image-bridge 生成；统一提示词风格基调（史诗历史画卷、写实油画与水墨意蕴结合、无文字、宽幅 3:2 或 16:9）；存 `assets/images/panorama/`。
2. **历史照片**：优先从 Wikimedia Commons 下载公有领域老照片（1949 年前的中国历史照片绝大多数已进入公有领域）；每张在 `CREDITS.md` 记录来源 URL 与许可；下载失败或无合适照片的用 AI 生成替代并标注"AI 复原想象图"。
3. 页面上 AI 生成图注明"AI 生成想象图"，历史照片注明出处，科普严谨性优先。

## 10. 史实保障

- 数据先行：先完成全部 `data/*.js` 再写游戏代码；数据文件独立可增改。
- 编写时逐条核对公认史实（时间、地点、人物、因果以中学/大学通行近代史叙述与权威工具书口径为准）。
- 完成后运行一次独立的**史实复核**（fact-check pass），交叉检查所有日期与陈述。
- 争议性表述从谨慎：只呈现学界公认结论，不采用野史。

## 11. 校验与测试

- `validate.html`：打开自动校验——
  - 事件按时间升序且都落在所属章节年份区间内；
  - 所有 `personIds` / `choiceId` / 图片路径引用存在；
  - 每个抉择点恰有一个 `correct: true` 且各选项均有 feedback；
  - 各章节点数、总节点数、抉择点数达标（≥70 / ≥25）。
- 计分逻辑以纯函数实现，`validate.html` 内附带用例断言。
- 人工验收：file:// 双击打开全程走一遍（含答错路径、静音、重开、人物星图）。

## 12. 明确不做（YAGNI）

- 不做后端、账号系统、排行榜联网功能。
- 不做多语言（仅简体中文）。
- 不做历史改变的"架空分支"玩法（与需求的"严格尊重历史"冲突）。
- 不做移动端原生打包；但布局做基础自适应，手机浏览器可玩。
