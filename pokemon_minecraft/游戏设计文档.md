## 1. 项目概述

**一句话**：一个运行在浏览器里的、我的世界像素（体素）画风的第三人称宝可梦开放世界游戏——玩家直接操控自己的出战宝可梦在野外探索，与野生精灵实时战斗、捕捉、升级进化、回村补给购物，挑战道馆。

**核心玩法循环**：

```
野外探索 → 遭遇野生精灵 → 实时战斗（技能 1~4）
    ↑                          ↓
 回村补给 ←—— 削弱后投精灵球捕获 / 击败获得经验与金币
（护士回复/商人购物）           ↓
    ↑          队伍成长（升级 / 学技能 / 进化 / 换队员）
    └────────← 挑战道馆（位于村庄）→ 徽章解锁更高级区域
```

**关键设定**：
- 玩家没有独立的人类角色，**玩家 = 当前出战的宝可梦**（第三人称跟随镜头）。
- 队伍上限 **6 只**；捕获第 7 只时必须先放生现有一只（或放弃新精灵）。
- 战斗为**实时制**：技能有冷却，自动瞄准最近的敌对目标，头顶实时血条。
- 每只精灵最多 **4 个技能**（数字键 1–4），随等级学习新技能，超过 4 个需替换。
- 数字键 5–9 为道具快捷栏（回复药、解异常药、各种精灵球等）。
- **村庄**是安全区与补给点：护士免费回复、商人售卖道具，道馆都建在村庄里。
- 进化、异常状态等数值**尊重宝可梦官方设定**（以第七世代及之后的机制为准），实时制放不进去的地方做最小化适配并在文中注明。

## 2. 技术方案

沿用 `设计.md` 的结论，按本项目实际需求裁剪：

| 项目 | 选择 | 说明 |
|---|---|---|
| 渲染 | **Three.js（WebGL2）** | r128 本地文件 `assets/lib/three.min.js`，无网络依赖 |
| 语言/构建 | 第一阶段 **原生 JS + ES Module，无构建工具** | `python3 -m http.server` 即可跑；规模大了再迁 Vite + TS |
| 地形 | **Chunk（16×16×48）+ 只生成暴露面 + 合并 BufferGeometry** | 本作不需要挖/放方块，chunk 网格一次生成、静态缓存 |
| 精灵/NPC 模型 | **体素模型 → 只生成暴露面的合并网格（`buildVoxelMesh`，已在示例中验证）** | 表面无接缝线；每只模型 1 次 draw call |
| 物理 | 自写 AABB 体素碰撞 + 重力 | 不引入 Rapier |
| 噪声 | simplex-noise（单文件内联实现） | 地形高度图 + 群系划分 |
| 状态/存档 | 纯 JS 对象 + `localStorage` | 队伍、背包、金钱、徽章、位置 |
| UI | HTML/CSS 覆盖层（Minecraft 风格） | 血条、技能栏、背包、商店、对话框都是 DOM |
| 音频 | **Web Audio API + 预生成素材**（详见 §14） | BGM/语音用 MiniMax API 离线批量生成为本地 mp3；技能音效运行时 8-bit 合成；游戏运行时不调任何外部 API |
| Web Worker | 暂不使用 | 地图有限，首次生成 <1s；卡了再上 |

**性能红线**：地形按 chunk 合并；每只精灵/NPC 一个合并网格；贴图 `NearestFilter`；同屏活跃野生精灵上限 ~20 只（按与玩家距离激活/休眠）。

## 3. 美术与素材管线（像素化宝可梦）

### 3.1 已定案：路线 A 手工体素精模（主路线）

经示例审查（`examples/voxel-viewer.html`），**全部登场精灵采用手工体素精模**：
- 用代码逐方块搭建（`box` / `bevelBox` 辅助函数 + 镜像），渲染用**只生成暴露面的合并网格**（无方块边界线，已验证）。
- 部件分组：`body / head / earL / earR / armL / armR / legs / tail`，供程序化动画（待机浮动、走路摆动 ±25°、受击闪白、濒死倾倒）。
- 1 体素 = 游戏世界 1/8 方块（精灵身高 1.5~3 个方块，与 MC 生物同比例）。
- 登场精灵控制在 **约 34 种**（含进化链，见 4.1 分布表），按里程碑分批建模。
- 路线 B（精灵图自动体素化，`examples/sprite-voxelizer.html`）保留为远期扩充图鉴的量产备选，不进第一版。

### 3.2 素材来源

- 配色/轮廓参考：PokeAPI 官方仓库 Gen5 96×96 像素图（已下载到 `assets/sprites/`）。
- 现成 voxel 模型（Sketchfab/CGTrader 等）因画风不统一、格式授权混乱，不采用。

### 3.3 NPC 模型

村民/护士/商人也用手工体素模型（MC 村民比例：大头、粗鼻、长袍）：
- **护士**：白粉配色 + 护士帽（红十字），驻守宝可梦中心。
- **道具商人**：棕袍 + 背篓 + 金币袋，头顶 `$` 浮动标记。
- **村民**：3~4 套换色袍子（农夫/渔夫/老人），随机生成。

## 4. 世界设计

**有限开放世界**：512×512 方块（32×32 个 chunk），一次性生成，出生点在中央草原村旁。

### 4.1 群系与精灵分布（含进化链，进化等级为官方设定）

| 群系 | 地形特征 | 野生等级 | 野生精灵（→ 进化链） |
|---|---|---|---|
| 中央草原 | 平缓草地、橡树、花丛 | 2–8 | 皮卡丘（雷之石→雷丘）、小拉达（Lv20→拉达）、波波（Lv18→比比鸟→Lv36→大比鸟）、皮皮（月之石→皮可西，夜间出现）、妙蛙种子（Lv16→妙蛙草→Lv32→妙蛙花） |
| 森林 | 密集树木、蘑菇 | 5–14 | 绿毛虫（Lv7→铁甲蛹→Lv10→巴大蝶）、独角虫（Lv7→铁壳蛹→Lv10→大针蜂）、走路草（Lv21→臭臭花，叶之石→霸王花）、伊布（水/雷/火之石→水伊布/雷伊布/火伊布） |
| 湖泊水域 | 湖、沙滩、芦苇 | 8–18 | 杰尼龟（Lv16→卡咪龟→Lv36→水箭龟）、鲤鱼王（Lv20→暴鲤龙）、可达鸭（Lv33→哥达鸭）、玛瑙水母（Lv30→毒刺水母） |
| 火山岩地 | 裸岩、岩浆池（伤害地块） | 14–24 | 小火龙（Lv16→火恐龙→Lv36→喷火龙）、卡蒂狗（火之石→风速狗）、小拳石（Lv25→隆隆石→Lv40→隆隆岩*）、鸭嘴火兽 |
| 雪山 | 雪块、冰面（滑） | 18–30 | 六尾-阿罗拉（冰之石→九尾-阿罗拉）、小海狮（Lv34→白海狮）、卡比兽（不进化） |
| 夜间/全图 | 夜晚出没 | 10–20 | 鬼斯（Lv25→鬼斯通→Lv40→耿鬼*） |

\* 鬼斯通、隆隆石官方为**通信交换进化**，单机版本地化为 Lv40 进化（对官方设定的唯一调整，文档如实注明）。

- 高度图：2 层 simplex noise 叠加，水面高度固定。
- 装饰：树、草丛（遭遇加成）、发光矿石、昼夜循环（10 分钟一天，夜间出幽灵系）。
- 道具刷新点：地面旋转发光掉落物（3 分钟重生）；宝箱（固定位置一次性，给稀有球/进化石/大量药）。

### 4.2 村庄（新增）

世界固定生成 **3 座村庄**，村庄由预制体素建筑拼装，坐落在群系交界处：

| 村庄 | 位置 | 建筑构成 | 特色 |
|---|---|---|---|
| 草原村（出生村） | 中央草原 | 宝可梦中心、商店摊位、民居×4、**岩系道馆**、农田 | 新手教学村，村民对话含玩法提示 |
| 湖畔村 | 湖泊水域旁 | 宝可梦中心、商店摊位、民居×3、码头 | 无道馆；商人出现概率最高（见 5.2） |
| 火山村 | 火山岩地边缘 | 宝可梦中心、商店摊位、民居×3、**火系道馆** | 石砖+岩浆装饰主题 |

村庄规则：
- **道馆都在村庄里**（岩馆在草原村、火馆在火山村），门口有指示牌。
- 村庄是**安全区**：范围内不刷新野生精灵；玩家进村立即脱战、敌对野怪回头。
- 建筑风格：MC 村庄语言——石径、木屋（橡木框架+泥墙）、火把、田地、井。
- 每座村庄必有一间**宝可梦中心**（红色屋顶，室内有回复台）。

### 4.3 村庄人口（随机生成）

每次进入游戏世界时按规则随机生成村庄人口：
- **护士**：每座宝可梦中心**常驻 1 名**（补给可靠性优先，不参与随机；这是对"随机出现"的设计取舍——治疗点必须稳定可用）。
- **道具商人**：**随机出现**——每个游戏日（10 分钟）开始时，以 70% 概率出现在随机一座村庄的商店摊位营业一整天，头顶 `$` 标记；小地图上标出当日位置。稀有商品每日轮换（见 5.2）。
- **村民**：每村随机 3~6 名，随机外观与名字，在村内游荡；按 `F` 对话，从语料表随机说闲话（玩法提示、传闻："听说雪山深处有只很大的宝可梦…"）。

## 5. NPC 交互与经济系统（新增）

### 5.1 宝可梦回复护士

- 对话按 `F` → "要为您的宝可梦恢复健康吗？" → 确认后 3 秒回复动画（队伍图标逐个亮起 + 音效）。
- 效果（官方宝可梦中心设定）：**全队 HP 回满 + 解除所有异常状态**，完全免费，无次数限制。
- **复活点绑定**（官方设定）：使用过某村护士后，该宝可梦中心成为玩家的复活点；队伍全灭时传送回最近使用过的宝可梦中心，队伍回满（替代 v1 的"出生点半血复活"）。

### 5.2 宝可梦道具商人

按 `F` 打开商店界面（MC 交易风格：左列商品/右侧详情/底部金钱）。

**常驻商品**（价格参考官方作品）：

| 商品 | 价格 | 商品 | 价格 |
|---|---|---|---|
| 精灵球 | ¥200 | 解毒药 | ¥100 |
| 超级球 | ¥600 | 麻痹药 | ¥200 |
| 高级球 | ¥1200 | 烧伤药 | ¥250 |
| 伤药（回 20） | ¥300 | 解冻药 | ¥250 |
| 好伤药（回 60） | ¥700 | 苏醒药 | ¥250 |
| 全满药（回满） | ¥2500 | 万灵药（解全部异常） | ¥600 |

**稀有栏**（每日随机上架 2~3 种）：火之石 / 水之石 / 雷之石 / 叶之石 / 月之石 / 冰之石（各 ¥3000）、大师球（1% 概率上架，¥50000）。

### 5.3 金钱

- 来源：击败野生精灵掉落金币方块（约 敌方等级×3）、道馆通关奖励（¥2000 / ¥5000）、卖道具、宝箱。
- 全灭惩罚（官方设定）：损失身上金钱的一半。
- HUD 右上角显示金钱；存档保存。

## 7. 精灵系统

### 7.1 数据结构（示意）

```js
// 图鉴静态数据 species.js
{
  id: 25, name: "皮卡丘", types: ["electric"],
  baseStats: { hp: 35, atk: 55, def: 40, spd: 90 },   // 官方种族值
  catchRate: 190,
  expYield: 112,
  growthRate: "medium",        // 经验组: fast | medium | slow
  evolution: { method: "stone", item: "thunderstone", to: 26 },  // 或 {method:"level", level:16, to:2}
  learnset: [ { lv:1, move:"tackle" }, { lv:5, move:"thundershock" }, ... ],
  model: "models/pikachu.js"
}

// 玩家拥有的实例
{
  speciesId: 25, nickname: null, level: 12, exp: 1728,
  ivs: { hp: 9, atk: 14, def: 3, spd: 12 },   // 个体值 0~15,捕获时随机
  curHp: 31, maxHp: 38,
  status: null,                // 主异常: poison|badpoison|paralysis|burn|freeze|sleep|null
  volatile: [],                // 挥发性: confusion 等
  moves: ["thundershock", "quickattack", "tackle"],
  noEvolve: false,             // 玩家选择"永不进化"
}
```

### 7.2 细化等级系统（官方公式）

- **属性计算**（官方初代公式，含个体值 IV 0~15，不做努力值）：
  - `HP = floor((种族值 + IV) × 2 × Lv / 100) + Lv + 10`
  - `其他 = floor((种族值 + IV) × 2 × Lv / 100) + 5`
  - IV 在捕获/遭遇时随机，让同种精灵有个体差异。
- **经验曲线**（官方经验组，升到 Lv 所需总经验）：
  - 中速组：`Lv³`（如 Lv10=1000，Lv50=125000）
  - 快速组：`0.8 × Lv³`（鲤鱼王、皮皮等）
  - 慢速组：`1.25 × Lv³`（御三家最终形、卡比兽等）
- **经验获取**：击败奖励 `= expYield × 敌方等级 / 7`；队伍未出战成员分得 50%。
- **等级上限** 100；等级压制体现在属性公式的 Lv 因子里。
- **学技能**：升级触发 learnset → 不足 4 个直接学会；已满 4 个弹替换面板（可放弃）。进化时也可能触发新技能学习。

### 7.3 进化系统（新增，官方设定）

**两种进化方式**：

1. **等级进化**：升到指定等级时触发。官方对应关系见 4.1 分布表（如 小火龙 Lv16→火恐龙 Lv36→喷火龙；绿毛虫 Lv7→铁甲蛹 Lv10→巴大蝶）。
2. **进化石进化**：在背包中对队伍成员使用对应进化石，立即触发。官方对应表：

| 进化石 | 可进化精灵（本作登场部分） |
|---|---|
| 雷之石 | 皮卡丘→雷丘、伊布→雷伊布 |
| 火之石 | 卡蒂狗→风速狗、伊布→火伊布 |
| 水之石 | 伊布→水伊布 |
| 叶之石 | 臭臭花→霸王花 |
| 月之石 | 皮皮→皮可西 |
| 冰之石 | 六尾-阿罗拉→九尾-阿罗拉 |

**进化流程与规则**：
- 触发后播放进化动画：模型白光闪烁 → 剪影渐变为新形态 → 星星粒子 + "恭喜！XX 进化成了 XX！"。
- **可取消**（官方 B 键设定）：动画期间按 `Esc` 中断进化，之后每次升级会再次询问；队伍面板可为单只精灵勾选"永不进化"。
- 进化后：种族值更换 → 属性按 7.2 公式重算（当前 HP 百分比保留）；技能、经验、等级、IV 保留；进化瞬间检查新形态的 learnset 补学技能。
- 进化石为消耗品；对不匹配的精灵使用会提示"没有反应"。
- 通信交换进化（鬼斯通→耿鬼、隆隆石→隆隆岩）本地化为 Lv40，见 4.1 注。
- 图鉴按进化链分组记录（捕获任一形态点亮对应格）。

### 7.4 队伍上限与放生

同 v1：满 6 只时捕获成功弹 7 选 1 放生面板；放生动画为模型粒子化消散；不做 PC 仓库。

## 8. 战斗系统（实时）

### 8.1 遭遇与仇恨

同 v1（警戒圈 6 方块、脱战 20 方块、村庄为安全区）。补充：
- 玩家精灵 HP 归零：自动切换下一只可战成员；**全灭则传送回最近使用过的宝可梦中心**，全队回满，**金钱减半**（官方设定）。

### 8.2 技能与伤害

- 技能字段：`{ name, type, category(物理/特殊/变化), power, accuracy, cooldown, range, castTime, effect, effectChance, anim }`。
- 冷却 1.5s（小招）~ 8s（大招）；前摇 0.2~0.5s。
- 伤害公式（官方简化）：

```
damage = ( (2 × Lv / 5 + 2) × power × atk / def / 50 + 2 )
         × 属性克制(0.25/0.5/1/2/4) × STAB(1.5) × random(0.85~1.0)
```

- 命中判定：按技能 accuracy 掷骰（实时制下未命中显示"MISS"飘字）。
- 属性克制：先做 9 系（普/火/水/草/电/岩/毒/幽灵/冰），完整 18 系二期。
- 头顶血条三段变色 + 属性色伤害数字 + "效果绝佳!" 提示。

## 14. 配音配乐系统（新增）

音频素材管线基于 `配音配乐/` 目录下的 MiniMax API 文档（`minimax_music.md` 音乐生成、`minimax_sound.md` 语音合成 T2A）。
**核心原则：所有 AI 生成的音频都在开发期离线批量生成为本地 mp3，游戏运行时只播放本地文件，不调用任何外部 API**（零延迟、可离线、不产生运行时费用）。

### 14.1 运行时音频引擎（Web Audio API）

- 一个 `AudioContext` + 三条独立总线（GainNode）：**BGM / 音效 SFX / 语音 Voice**，各自音量可在设置菜单单独调节（0~100%，存档保存）。
- 浏览器自动播放策略：首次用户点击（标题界面"开始游戏"）后再 `resume()` AudioContext。
- **SFX 池**：同种音效并发上限 3，播放时随机 ±10% 音高偏移，避免连发时的机械重复感。
- **3D 空间音效**：野怪叫声、技能爆炸等世界内声音用 `PannerNode` 按距离衰减定位（听者=镜头）。
- **BGM 切换**：双通道交叉淡入淡出 2s；一次性短乐句（jingle，如胜利/进化）会暂停 BGM，播完淡回。

### 14.2 背景音乐（MiniMax 音乐生成 API）

用 `POST /v1/music_generation`（`model: music-2.6` 或限免的 `music-2.6-free`），统一设 `is_instrumental: true` 生成纯音乐，`output_format: url` 下载存为 `assets/audio/bgm/*.mp3`。**所有曲目 prompt 统一带"8位芯片音乐/chiptune/复古游戏配乐"风格词**，与像素画风统一。

**场景配乐表（环境不同音乐不同，含生成 prompt）**：

| 曲目 | 触发场景 | 生成 prompt（示意） | 循环 |
|---|---|---|---|
| title | 标题界面 | 8位芯片音乐, 明亮冒险启程, 复古掌机游戏标题曲, 轻快难忘的主旋律 | ✓ |
| grassland | 中央草原（白天） | 8位芯片音乐, 田园清新, 轻松愉快的探索, 阳光草地 | ✓ |
| forest | 森林 | 8位芯片音乐, 神秘幽静的森林, 木管质感, 微风与鸟鸣意象 | ✓ |
| lake | 湖泊水域 | 8位芯片音乐, 舒缓流动, 竖琴般清凉的水边旋律 | ✓ |
| volcano | 火山岩地 | 8位芯片音乐, 低音威压, 紧张灼热, 缓慢有力的鼓点 | ✓ |
| snow | 雪山 | 8位芯片音乐, 空灵八音盒, 寒冷寂静, 缓慢飘雪 | ✓ |
| night | 夜晚（全图变奏） | 8位芯片音乐, 安静月夜, 温柔摇篮曲, 稀疏音符 | ✓ |
| village | 村庄（覆盖群系曲） | 8位芯片音乐, 温馨村庄, 手风琴民谣感, 炊烟与集市 | ✓ |
| battle_wild | 野外战斗 | 8位芯片音乐, 快节奏战斗, 紧张兴奋, 复古RPG遇敌曲 | ✓ |
| battle_gym | 道馆战 | 8位芯片音乐, 激烈决战, 强劲鼓点与铜管气势, BOSS战 | ✓ |
| victory | 战斗胜利 | 8位芯片音乐, 短促凯旋号角, 胜利喝彩 | jingle |
| evolution | 进化演出 | 8位芯片音乐, 神圣渐强, 蜕变的光辉, 高潮收尾 | jingle |
| capture | 捕获成功 | 8位芯片音乐, 得意短乐句, 收获喜悦 | jingle |
| defeat | 队伍全灭 | 8位芯片音乐, 低沉失落, 缓慢短句 | jingle |

**BGM 触发规则**：按玩家所在群系/村庄区域播对应曲（跨区 2s 交叉淡入淡出）；夜晚切 night 变奏；进入敌对状态 → battle_wild（道馆内 → battle_gym），脱战 3s 后淡回环境曲；胜利/捕获/进化 jingle 打断后恢复。

### 14.3 NPC 语音（MiniMax 语音合成 T2A）

用 `POST /v1/t2a_v2`（`model: speech-2.8-hd`，支持情绪与语气词标签），为每条固定台词离线生成 mp3，存 `assets/audio/voice/`。对话框打字机文字与语音同时开始；`subtitle_enable: false`（游戏自带文字）。

**音色分配（voice_id 从系统音色列表选定，混音可用 timbre_weights）**：

| 角色 | 音色方向 | emotion | 台词示例（生成文本可带语气词/停顿标记） |
|---|---|---|---|
| 护士 | 甜美温柔女声（如 female-tianmei 系） | happy | "欢迎来到宝可梦中心！要为您的宝可梦恢复健康吗？"、"您的宝可梦已经完全恢复健康了！<#0.3#>期待您再次光临！" |
| 道具商人 | 成熟爽朗男声 | happy / fluent | "(laughs) 欢迎光临！看看有什么需要的吧！"、"这可是稀罕货哦。"、"谢谢惠顾！" |
| 村民×3 套 | 青年男 / 少女 / 老者（pitch 微调区分） | calm / surprised | 闲聊语料表：玩法提示、传闻（"听说雪山深处住着一只很大的宝可梦…"）、寒暄 |
| 岩馆馆主 | 低沉厚重男声（voice_modify.pitch 调低） | calm→angry | 战前："想拿徽章？先过我这关！"；战败："好硬的意志…徽章拿去吧！" |
| 火馆馆主 | 热血高亢男声 | angry / happy | 战前："让你见识火焰的热情！"；战败："燃烧殆尽了…你赢了！" |
| 系统旁白（可选） | 清晰中性播报 | calm | "获得了岩石徽章！"等关键事件 |

- 台词集中在 `data/dialogues.js` 维护，每条带 `voiceFile` 字段；村民随机闲聊从语料池抽取（每条都有预生成语音）。
- 多音字用 `pronunciation_dict` 修正（如精灵名读音）；`language_boost: "Chinese"`。
- 语音触发：对话开始播对应 mp3，玩家按 `F` 跳过时立即停止；同一 NPC 短时间重复对话不重播欢迎语（防轰炸）。

### 14.4 技能特效音与精灵叫声（8-bit 程序化合成）

MiniMax 两个接口分别面向音乐和语音，不适合毫秒级技能音效；技能音效改用 **Web Audio 程序化合成（jsfxr 风格振荡器+噪声+包络）**，运行时即时生成——零素材体积，且芯片感与像素画风、chiptune BGM 天然统一。

| 音效 | 合成配方（波形/包络） |
|---|---|
| 电系（电击/十万伏特） | 方波高频快速抖动 + 白噪声脉冲，短促"滋啦" |
| 火系（火花/喷射火焰） | 粉噪声低通扫频，"呼——轰"渐强 |
| 水系（水枪/水炮） | 白噪声高通 + 正弦下滑音，"咻——哗" |
| 草系（藤鞭/飞叶快刀） | 锯齿波快速上滑短音，"唰" |
| 岩系（落石/铁头） | 低频方波 + 噪声爆发，沉闷"咚" |
| 幽灵/超能 | 三角波慢颤音 + 混响感延迟，"呜～" |
| 冰系（冰冻光束） | 高频正弦碎音簇，"叮铃" |
| 通用命中 / 效果绝佳 | 短方波"啪" / 上行双音"叮咚!" |
| UI（翻页/购买/错误） | 极短方波 blip 三件套 |
| 精灵球（抛出/吸入/摇晃/成功） | 抛物线上滑音 / 下滑吸入 / 节奏"咔哒"×3 / 星星琶音 |
| 状态施加（麻痹/中毒/睡眠…） | 每种异常一个 0.3s 特征短音（黄电滋滋/毒泡咕噜/哈欠滑音） |
| **精灵叫声** | 官方初代叫声本就是芯片合成音——每种精灵配一组合成参数（基频/滑音方向/时值/波形），遭遇、受击、濒死、捕获时播放，同族异形态共享变调版本 |

合成参数集中在 `data/sfxPresets.js`，一种技能一条配方，新技能只加参数不加素材文件。

### 14.5 环境音（Ambience）

第四条低音量循环层，跟随场景叠在 BGM 之下（也可用音乐 API 以"纯氛围音"prompt 生成）：白天草原鸟鸣、夜晚虫鸣、水边流水、火山低频隆隆、雪山风声、村庄人声嘈杂+鸡叫。切换随 BGM 一起交叉淡化。

### 14.6 离线生成管线与密钥安全

- 批量脚本 `tools/gen-audio.mjs`（Node 18+，原生 fetch）：读取 `data/dialogues.js` 台词表与 `tools/bgm-prompts.json` 曲目表 → 逐条调 MiniMax API → 下载 mp3 到 `assets/audio/{bgm,voice,ambience}/` → 生成清单 `assets/audio/manifest.json`（文件名/时长/触发键）。
- 限免模型（`music-2.6-free`）RPM 低：脚本串行请求 + 失败重试 + 请求间隔；`output_format: url` 的链接 24 小时有效，脚本内立即下载。
- 已有素材跳过（按台词/prompt 内容哈希命名），增量生成。
- **密钥安全**：API Key 存放于 `配音配乐/mini_max_api`，只被离线脚本读取；**绝不写进任何前端代码或网页**（游戏运行时不联网）；该文件与生成脚本不得提交到公开仓库（.gitignore）。

## 20. 结局系统（v4 新增）

**通关目标**：集齐 2 枚徽章（岩系道馆 + 火系道馆）后，前往雪山深处挑战沉睡的**巨大卡比兽**。

- **Boss 设定**：Lv.40 卡比兽，2 倍巨大化模型，HP ×1.5 强化；平时在雪山深处（小地图 `★` 标注）熟睡（Z 粒子），呼应村民传闻"听说雪山深处有只很大的宝可梦…"。
- **挑战门槛**：按 `F` 交互时徽章不足 2 枚则提示"卡比兽挡住了去路…"；集齐后确认唤醒，进入 Boss 战（战斗曲 battle_gym）。
- **重置规则**：玩家逃离 50 方块以上，Boss 回满 HP 重新入睡，可反复挑战。
- **通关判定**：击败 **或** 捕获该卡比兽均算通关（可捕获，残血/异常状态/高级球提高机会，大师球必中）。
- **结局演出**：胜利 jingle + 星星粒子 + 通关对话框（冒险统计：徽章数、图鉴点亮链数、金钱、天数），通关标记 `completed` 写入存档；之后世界继续开放，自由探索集图鉴。

**开局难度调整（v4）**：
- 初始背包：精灵球×5、伤药×5、好伤药×2（原 伤药×2）。
- 出生村护士站在宝可梦中心**门口**迎客（头顶红十字浮动标记），出生点即达，方便新手随时免费回血练级（§5.1 护士常驻规则不变）。
