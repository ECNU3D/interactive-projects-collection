# 清明上河圖 · 入畫遊

用 Three.js 复原的《清明上河图》可漫游 3D 长卷：从郊野春光、汴河漕运、虹桥喧闐一路走进城内街市，行至妙处自动触发语音讲解（MiniMax TTS 生成），配以古风背景音乐。

## 运行

需要本地静态服务器（ES Module 限制，不能直接双击 index.html）：

```bash
cd 清明上河图
python3 -m http.server 8420
# 浏览器打开 http://localhost:8420
```

## 操作

| 输入 | 功能 |
|---|---|
| 滑鼠 | 环顾（点击画面锁定指针，Esc 释放） |
| W A S D / 方向键 | 行走 |
| Shift | 疾行 |
| M（或右上"遊"钮） | 憑虛御風（鸟瞰模式）切换 |
| 右上"樂"钮 | 静音 |
| **触屏（手机/平板）** | 左下虚拟摇杆行走（推满疾行），滑动画面环顾，按钮同右上 |

走进 13 处看点（虹桥险情、桥上争道、十千脚店、孙羊正店、赵太丞家……）会自动播放讲解并显示字幕。

**底部手卷进度条即《清明上河图》原卷**（故宫博物院藏本扫描，公有领域，取自 Wikimedia Commons）：按手卷"右起左行"的读卷方向，行走时朱色标记从卷首（右端郊野）移向卷尾（左端城内），走到哪里，标记就指向原画对应的段落——虹桥顶对应原卷 49.5% 处的虹桥，城门对应 18% 处的城门楼。鼠标悬停进度条可放大细看。封面亦以原卷长带缓缓展开作意境背景。

## 内容对照（依画中考证细节复原）

- **虹桥**：无柱贯木拱、通体丹红、桥头四根立鹤华表、桥上摊贩与文武争道（文官轿与武官马迎面相遇）
- **宋式小木作**：大宅悬山施博风板、悬鱼、惹草，斗拱、鸱吻、直棂窗
- **桥下险情**：大客船桅杆将倒未倒、船工撑篙、摇橹、桥上抛下的救援缆绳
- **汴河**：龟背篷漕船（带桅杆卷帆）、客船、纤夫纤绳、码头背粮力夫与监工
- **城门**：夯土城墙、排叉柱门洞、单檐庑殿城楼、胡人驭手的出城骆驼商队
- **人物服饰**（依宋制复刻）：士人团花织锦襕衫（下襕、圆领大袖）、平民麻布短褐、交领右衽襟边、展脚幞头、女子发髻、腰带、胡人毡帽、挑夫扁担、送餐托盘、执扇
- **街市招牌**（画中原文）：孫羊正店、十千腳店、新酒、久住王員外家、劉家上色沉檀楝香、王家紙馬、解、趙太丞家、飲子、神課·看命·決疑……
- **动效**：水流、炊烟、柳枝摆动、酒旗招展、飞鸟、驮炭驴队、数百市井人物自由活动
- **声画联动**：行至看点触发讲解时，驴队、驼队会同步出现在语音描述的位置（如驼队正出城门洞）

## 贴图与性能

- **程序化贴图**（全部 Canvas 生成，无外部资源）：瓦垄、茅草、木板木纹、粉墙斑驳、夯土夯层、砖缝、苇席编织、直棂窗、彩楼欢门红蓝彩帛、地面砂土笔触
- **材质通道**：所有静态几何按贴图通道合并（tile/wood/thatch/plaster/earthwall/brick/reed/lattice/silk），三向映射自动生成 UV
- **分批加载**：进入前分七个阶段异步构建（展卷/落墨/点苔/传神/写生/行舟/生烟），标题页显示进度
- **分块裁剪**：静态世界按画卷四段自动切块，按玩家位置距离裁剪，单帧 draw call 约 10–50

## 音频再生成

讲解词在 `audio/narrations.json`，重新生成配音/配乐：

```bash
cd audio && python3 gen_audio.py   # 使用 配音配乐/mini_max_api 中的密钥
```

已存在的 mp3 会跳过；删除对应文件即可重生成。
