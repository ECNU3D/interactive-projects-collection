# 星际火狐 · 深空突袭 (Star Strike)

星际火狐 64（N64）复刻版三维轨道射击游戏：开场剧情动画 + 每关战前剧情（AI 配音）、星域航线选关、六大关卡横跨城市/陨石带/沙漠/毒海/雪原/熔岩星，机枪 + 锁定导弹双武器，每关一场 Boss 战，通关后播放结局并开启更高难度的下一周目，AI 生成配乐全程陪伴。

## 运行

需要通过本地 HTTP 服务器打开（ES Module 限制，不能直接双击 index.html）：

```bash
cd 本目录
python3 -m http.server 8765
# 然后浏览器打开 http://localhost:8765/
```

macOS 也可以直接双击 `启动游戏.command`。

## 关卡（复刻 Star Fox 64 主线）

| # | 关卡 | 环境 | Boss |
|---|---|---|---|
| 1 | 科内利亚 | 首都城市（高楼、地面炮台、坦克） | 攻击母舰 |
| 2 | 梅特奥陨石带 | 深空碎石 | 陨石粉碎者 |
| 3 | 卡蒂娜防线 | 沙漠基地 | 飞碟母舰 |
| 4 | 佐内斯毒海 | 污染海域（探照灯） | 深海潜艇 |
| 5 | 福尔图娜雪原 | 冰原 | 沃尔夫小队（三机编队） |
| 6 | 维诺姆核心 | 熔岩地狱 | 皇帝安德罗斯 |

通关解锁下一关（进度存于 localStorage），选关界面可自由重玩已解锁战区。每关出击前播放该关专属战前剧情（可点击/回车跳过）。

击败最终 Boss 后播放通关结局演出，随后进入下一周目：关卡推进重置（重新从第一关打起），敌人血量（每周目 +40%）与伤害（每周目 +25%）递增，周目数持久化（localStorage `sf64_cycle`）并显示在主菜单与选关界面，可无限循环挑战。主菜单右下角的「重置进度」按钮可清空全部通关记录与周目数。

## 武器系统

- **机枪**：LV.1 单发 → LV.2 双联 → LV.3 三联 → LV.4 等离子重炮（击毁敌机拾取 `W` 道具升级）。
- **导弹**：按住右键/F，准星扫过敌机或 Boss 弱点开始锁定（黄框→红框），松开后导弹自动追踪，可同时锁定 4 个目标。
- **道具**：`S` 护盾恢复 / `B` 智能炸弹（清屏）。

## 音频

- `assets/audio/bgm_*.mp3`：每关专属环境配乐 + Boss 战曲 + 开场/菜单/胜利曲（MiniMax music-2.6 生成）。
- `assets/audio/*.mp3`（配音）：开场旁白、各关战前剧情、通关结局、佩珀将军任务简报、佩比教学、法尔科/斯利皮无线电（MiniMax speech-2.8-hd 合成）。
- 生成脚本：`tools/gen_audio.mjs`（API 密钥从 `配音配乐/mini_max_api` 读取，已生成的自动跳过）。
- 射击/爆炸/锁定等音效为 WebAudio 实时合成。

## 技术

Three.js r160（本地 `vendor/`，无构建步骤），原生 ES Modules，零依赖。
贴图：NASA 公开图片 + Canvas 程序化生成（装甲/岩石/天空/地表）。

## 文件结构

```
index.html        页面 + HUD + 菜单/剧情/选关界面
js/main.js        主循环 / 输入 / 锁定导弹 / 碰撞 / 音频 / 剧情与选关流程

js/models.js      战机 / 敌机 / Boss / 建筑等三维模型
js/textures.js    程序化贴图 + NASA 图片合成
assets/textures/  NASA 星云、银河、行星图片
assets/audio/     AI 生成配乐与配音
tools/gen_audio.mjs  音频批量生成脚本
tools/model_preview.html  模型预览页（本地服务器打开，支持 #front/#ship/#wolfen/#andross/#sub 机位）
vendor/           three.module.js
```
