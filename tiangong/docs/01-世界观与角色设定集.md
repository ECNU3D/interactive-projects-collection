# 天宫模拟器 · 世界观与角色设定集

> 版本 v0.1 ｜ 2026-08-08
> 依据：《西游记》通行百回本（世德堂系统），原文核对底本见 `docs/research/`
> 本文档是内容层的唯一事实来源（SSOT）。技术、美术、音频文档中出现的一切角色名、地名、台词，以本文档为准。

## 0. 项目定位

| 项 | 定义 |
|---|---|
| 一句话 | 你是齐天大圣。天宫在你脚下，你可以飞去任何地方，跟任何一位神仙说话。 |
| 核心体验 | **自由漫游 + NPC 语音对话**。无强制任务线，无失败状态，无战斗。 |
| 时间设定 | **蟠桃会前夕**。悟空已受封齐天大圣、已在督理蟠桃园，但尚未偷桃。这是天宫最"完整"也最"体面"的一刻——所有殿宇未毁、所有神仙尚未与你翻脸，同时空气里已有全书最大的一场事故在酝酿。 |
| 情绪基调 | 庄严 + 荒诞。天宫是一座极其宏大、极其官僚、极其安静的宫殿群，而你是唯一一个在里面大声说话的人。 |
| 时长 | 首次完整漫游 30–45 分钟；重复游玩靠对话分支与彩蛋。 |
| 玩家能力 | 飞行（筋斗云）、对话、少量环境交互（敲钟、开门、摘桃、看照妖镜）。**不能战斗、不能杀死任何 NPC。** |

### 0.1 为什么选"蟠桃会前夕"

1. **建筑完整**：第 7 回天宫被打得"九曜星闭门闭户，四天王无影无形"，若设定在闹天宫之后，场景必须做破损版本，程序化生成的成本翻倍。
2. **社交权限最大**：第 5 回原文写悟空此时"见三清称个'老'字，逢四帝道个'陛下'……俱只以弟兄相待"。这一句直接授权了本作的核心玩法——**你可以走进任何一座殿，跟任何人平辈说话**。这是全书唯一一段悟空与天庭和平共处的时期。
3. **戏剧张力免费获得**：玩家知道后面会发生什么，NPC 不知道。所有对话自带反讽。
4. **蟠桃园归你管**：给了玩家一个"家"和一个天然的初始出生点。

### 0.2 内容红线

- 不做战斗、不做死亡、不做血腥。
- 不给任何神仙设计"被玩家羞辱"的分支。悟空可以贫嘴，NPC 可以不高兴，但不做单方面的贬低。
- 佛道人物一律按文学角色处理，不涉及现实宗教教义的评判。
- 所有原文引用必须准确。宁可不引，不可错引（见 §5 讹误清单）。

## 1. 天宫地理

### 1.1 分层结构

原著对天宫空间没有系统交代，本作在**不与原文冲突**的前提下，把散见于各回的地点组织为五层。层与层之间靠云海分隔，玩家用筋斗云垂直穿越。

```
                    ┌─────────────────────────────┐
   第五层 · 离恨天   │  兜率宫（三十三天之上）        │  ← 独立浮岛，最高，最冷清
                    │  朱陵丹台 · 丹房 · 八卦炉      │
                    └─────────────────────────────┘
                              ↑ 云梯 / 筋斗云
                    ┌─────────────────────────────┐
   第四层 · 月天     │  广寒宫 · 桂殿 · 蟾宫         │  ← 侧向浮岛，永夜，清冷
                    └─────────────────────────────┘
                              ↑
   ┌────────────────────────────────────────────────────────┐
   │  第三层 · 内苑                                           │
   │  瑶池宝阁 ── 蟠桃园（三段）── 齐天大圣府（园右首）        │  ← 玩家出生点在此
   │                                    安静司 · 宁神司       │
   └────────────────────────────────────────────────────────┘
                              ↑ 复道回廊
   ┌────────────────────────────────────────────────────────┐
   │  第二层 · 宫城（主轴）                                    │
   │  三十三座天宫 · 七十二重宝殿（程序化生成的宫殿海）          │
   │  寿星台 ── 炼药炉 ── 朝圣楼 ── 通明殿 ── 灵霄宝殿          │
   │  侧翼：斗牛宫（星宿点卯）· 披香殿 · 御马监 · 斩妖台         │
   └────────────────────────────────────────────────────────┘
                              ↑ 盘龙大柱 / 长桥丹凤
   ┌────────────────────────────────────────────────────────┐
   │  第一层 · 天门                                           │
   │  南天门（主入口）· 东天门 · 西天门 · 北天门（均可达）        │
   │  南天门外：天河渡口（天蓬元帅驻地）                         │
   │  门外：无边云海，下界隐约可见                              │
   └────────────────────────────────────────────────────────┘
```

**动线依据（原文可证）**

- 第 4 回骈文是全书唯一一次完整"进宫路线"，按 `南天门 → 里壁厢（盘龙柱/长桥丹凤）→ 三十三宫七十二殿 → 寿星台/炼药炉 → 朝圣楼 → 灵霄宝殿` 逐段推进。本作第一、二层的主轴严格照此排列。
- 第 31 回：「让他打入天门，直至**通明殿**下。早有张葛许邱四大天师问道……天师闻言，即进**灵霄殿**上启奏。」→ **通明殿是灵霄宝殿的前导殿**，相当于太和门之于太和殿。
- 第 7 回：悟空「只打到**通明殿里，灵霄殿外**」。→ **他从未打进灵霄宝殿**。这是本作最重要的一条空间纪律，见 §1.3。
- 第 4 回：齐天大圣府在「**蟠桃园右首**」。这是全书方位最明确的一处，直接决定了第三层的布局。
- 第 5 回：兜率宫在「**三十三天之上，乃离恨天**」。注意是"三十三天**之上**的离恨天"，不是"第三十三层天名叫离恨天"。第五层因此是一座**在所有天之上的孤岛**。
- 第 5 回：悟空从瑶池回家「一会把路差了，不是齐天府，却是兜率天宫」——**醉酒走错楼层**。本作应保留这条动线的可能性：从瑶池出来若不看路，云会把你带到最高处。

### 1.2 区域档案

共 16 个区域（A–O 共 15 个 + 天河渡口）。每个区域对应 `src/world/regions/` 下的一个模块（《02》§2）。

#### A. 南天门（第一层 · 入口）

| 项 | 内容 |
|---|---|
| 出处 | 第 1、4 回 |
| 原文形象 | 「碧沉沉，琉璃造就；明幌幌，宝玉妆成。两边摆数十员镇天元帅，一员员顶梁靠柱，持铣拥旄；四下列十数个金甲神人，一个个执戟悬鞭，持刀仗剑。」 |
| 功能 | 玩家首次进入的门户；教学关；界碑感 |
| 驻场 NPC | 增长天王（守将）、庞刘苟毕邓辛张陶八大力天丁（群众）、千里眼与顺风耳（门楼上）、巨灵神（门外）、天蓬元帅（天河渡口） |
| 可交互 | 向下俯瞰云海与下界；八大天丁的枪林可穿行；千里眼顺风耳会主动"报告"你的行踪（作为教学提示系统） |
| 氛围关键词 | 逆光、剪影、巨大、风声、金属反光 |
| 设计意图 | 让玩家第一眼就意识到"这里的人比你高一个数量级，但你可以直接走过去"。 |

> **东、西、北天门**：三座次要天门，**均可达**，各驻一位天王（东-持国、西-广目、北-多闻）。规模约为南天门的 1/3，形制相同、瓦色降一级。
> ⚠️ **西天门有原文依据**（第 5 回悟空偷丹后"从西天门，使个隐身法逃去"）；**东、北天门原著未见，属本作自拟**，须在考据栏标注。
> **天河渡口**（南天门外侧）：天蓬元帅所在。一条横亘云海的星河，八万水兵的营寨在岸边。原著只说他"掌管天河八万水兵"，未写天河形貌，**本作自拟**。

#### B. 主轴宫殿海（第二层）

| 项 | 内容 |
|---|---|
| 出处 | 第 4 回骈文 |
| 规模 | **三十三座天宫、七十二重宝殿**。原文举名者：遣云宫、毗沙宫、五明宫、太阳宫、化乐宫；朝会殿、凌虚殿、宝光殿、天王殿、灵官殿。**其余 90 余座原著未命名——这是程序化生成的合法授权**。 |
| 视觉母题 | 「一宫宫**脊吞金稳兽**」（正吻吞脊）；「一殿殿**柱列玉麒麟**」（陛前石兽） |
| 功能 | 主要的漫游空间。玩家在此获得"天宫大得离谱"的体感。 |
| 驻场 NPC | 稀疏。大部分殿是空的、锁着的、或者只有一个打盹的小仙吏。**空旷本身是内容**。 |
| 设计意图 | 天宫是一个庞大的官僚机构，绝大多数编制并不办事。这份"宏伟的冗余"是全书对天庭最尖锐的观察，用建筑说出来比用台词说出来好。 |

#### C. 寿星台 · 炼药炉（第二层）

- 出处：第 4 回「**寿星台**上，有千千年不卸的名花；**炼药炉**边，有万万载常青的瑞草。」
- 只有两句话的地方，正好做成两个安静的小景点：一座满是永不凋谢的花的台子，一座旁边长满灵芝瑞草的炉。
- NPC：寿星（南极老人星，第 7 回安天大会献"紫芝瑶草、碧藕金丹"）。

#### D. 朝圣楼（第二层）

- 出处：第 4 回，全书仅此一句：「绛纱衣，星辰灿烂；芙蓉冠，金璧辉煌。玉簪珠履，紫绶金章。**金钟撞动**，三曹神表进丹墀；**天鼓鸣时**，万圣朝王参玉帝。」
- 功能推断（原文未明说，标注为**本作设定**）：百官候朝、更衣、集散之地。
- 可交互重点：**金钟与天鼓可以敲**。敲响后远处宫殿群会有神仙陆续出现、列队、又散去——一次"朝会"的微型演出。这是本作最重要的单点交互。

#### E. 通明殿（第二层 · 外朝）

| 项 | 内容 |
|---|---|
| 出处 | 第 3、5、7、31 回 |
| 功能 | 进表、演礼、候旨、天师值守。天庭的**收发室兼秘书处**。 |
| 驻场 NPC | 四大天师（张道陵、葛仙翁、许旌阳、丘弘济）、引奏仙童、传言玉女 |
| 可交互 | 案上堆着各路神仙的表章（可读，是彩蛋文本的载体）；玩家可以"递状子"，天师会给出各种官腔回复 |
| 设计意图 | 四大天师是天庭里最有"人味"的一组，跟悟空插科打诨。这里是全场对话密度最高的地方，是**社交中枢**。 |

#### F. 灵霄宝殿（第二层 · 终点）

| 项 | 内容 |
|---|---|
| 出处 | 第 1、3、4、7 回。全称「**金阙云宫灵霄宝殿**」 |
| 原文形象 | 「**金钉攒玉户，彩凤舞朱门。复道回廊，处处玲珑剔透；三檐四簇，层层龙凤翱翔。**上面有个紫巍巍、明幌幌、圆丢丢、亮灼灼，**大金葫芦顶**；下面有**天妃悬掌扇，玉女捧仙巾**。……正中间，**琉璃盘**内放许多重重迭迭**太乙丹**；**玛瑙瓶**中插几枝弯弯曲曲**珊瑚树**。」 |
| 驻场 NPC | 玉皇大帝、天妃、玉女、掌朝天将、护驾仙卿 |
| **准入规则** | **默认不可进入。** 见 §1.3 |

#### G. 斗牛宫（第二层侧翼）

- 出处：第 31 回「又查那**斗牛宫外，二十八宿**，颠倒只有二十七位，内独少了奎星」。
- 功能：**星官点卯处**。天庭唯一被原文写实的考勤制度所在地。
- 可交互：一面点卯的名牌墙，二十八宿的牌子挂在上面，**奎木狼的牌子是空的**（他此刻正在下界当黄袍怪）。玩家问起，会引出天师那句名台词：「四卯不到，三日点卯一次，今已十三日了。」——玉帝答「天上十三日，下界已是十三年」。
- 这是全场最好的一个"设定说明装置"：用一块空名牌讲清了天上一日下界一年。

#### H. 御马监（第二层侧翼）

- 出处：第 4 回。
- 功能：**玩家的旧单位**。天马千匹，编制为监丞、监副、典簿、力士。
- 情绪：这里的人对你态度最微妙——你曾是他们的正堂管事，干得还相当不错（原文「弼马昼夜不睡，滋养马匹……那些天马见了他，**泯耳攒蹄**，倒养得肉肥膘满」），然后你掀了公案跑了。
- 可交互：喂马；马群见到你会「泯耳攒蹄」（低头贴耳）——一个不用台词的情感瞬间。
- 关键对话：与监丞重演那段品级问答（「此官是个几品？」→「没有品从」→「未入流」→「末等」）。**这是全作的情绪支点**，玩家在此理解自己为什么反出天宫。

#### I. 披香殿（第二层侧翼）

- 出处：第 31 回，有"侍香玉女"；第 87 回，玉帝在此立"米山面山金锁"三事。
- 原著无外观描写，**造型自拟**。本作定为：一座终年焚香、烟雾极浓的内廷小殿，光线全靠香烟中的丁达尔效应。
- 视觉功能：全场**体积光效果最集中的房间**，作为技术展示点。

#### J. 斩妖台 · 降妖柱（第二层边缘）

- 出处：第 7 回「押去**斩妖台**下，绑在**降妖柱**上，刀砍斧剁，枪刺剑刳，莫想伤及其身。」
- 本作处理：**空置、废弃、无人**。台上有一根柱子，柱身有砍痕。玩家走近，什么都不会发生。
- 设计意图：这是全作唯一的"预言"。玩家知道这根柱子是给谁准备的。不加任何台词。

#### K. 蟠桃园（第三层 · 出生点）

| 项 | 内容 |
|---|---|
| 出处 | 第 5 回 |
| 规模 | **三千六百株**，分三段各一千二百株 |
| 前段 | 花微果小，**三千年**一熟，食之「成仙了道，体健身轻」 |
| 中段 | 层花甘实，**六千年**一熟，食之「霞举飞升，长生不老」 |
| 后段 | 紫纹缃核，**九千年**一熟，食之「与天地齐寿，日月同庚」 |
| 视觉铁律 | 「**时开时结千年熟，无夏无冬万载迟**」——**同一棵树上花与果并存**，不遵循季节逻辑。这是本作最反常识也最"仙"的一条美术规则。 |
| 果实颜色梯度 | 前段青小 → 中段丰满 → 后段**紫纹缃核，果实饱满**。<br>⚠️ 原文中"花果稀疏，止有几个**毛蒂青皮**的"是**偷桃之后**的状态。本作时间点在偷桃之前，**后段树必须是完好的**。 |
| 园内建筑 | 「**左右楼台并馆舍，盘空常见罩云霓**」——有亭、有楼台、有馆舍，且整园在云上。 |
| 驻场 NPC | 蟠桃园土地；锄树、运水、修桃、打扫四类力士；齐天府二司仙吏 |
| 可交互 | 摘桃（三段各有不同的画面反馈）；在亭上"少憩"（触发一段视角演出）；土地会拦你、然后认出你、然后立刻改口 |

#### L. 齐天大圣府（第三层 · 家）

- 出处：第 4 回「玉帝即命工干官——**张、鲁二班**——在**蟠桃园右首**，起一座齐天大圣府，府内设个**二司：一名安静司，一名宁神司**。」
- 全新落成，崭新，气派，**空的**。
- 两块匾："安静司"、"宁神司"。玩家点击可以看到两位仙吏，他们的全部工作就是让你安静、让你宁神。
- **这是本作最大的一个冷笑话，且完全出自原著**。玉帝给一只闹事的猴子建了一座府，府里设了两个部门，一个叫安静，一个叫宁神。不需要任何加工。
- 可交互：五斗星君送任时赐的"御酒二瓶、金花十朵"就放在案上（第 4 回）。
- 出生点即此处的院子。

#### M. 瑶池宝阁（第三层）

| 项 | 内容 |
|---|---|
| 出处 | 第 5、6、7 回 |
| 原文形象 | 「**琼香缭绕，瑞霭缤纷，瑶台铺彩结，宝阁散氤氲。凤翥鸾腾形缥缈，金花玉萼影浮沉。**上排着**九凤丹霞扆**，**八宝紫霓墩**。**五彩描金桌，千花碧玉盆。**」 |
| 陈设可直接建模 | 九凤丹霞扆（御座屏风）、八宝紫霓墩（坐墩）、五彩描金桌、千花碧玉盆 |
| 状态 | **正在布置中，宾客未至**。第 5 回原文：「那里铺设得齐齐整整，**却还未有仙来**。」 |
| 驻场 NPC | 造酒的仙官、盘糟的力士、运水的道人、烧火的童子（长廊下） |
| 可交互 | 长廊酒缸（可看不可喝——喝了就进入第 5 回，超出本作范围）；席位牌可读，列出蟠桃会全部宾客名单 |
| 设计意图 | 一场即将开始、而你没被邀请的宴会。全场最强的情绪场。 |

#### N. 广寒宫（第四层）

- 出处：第 19、95 回。别名蟾宫、桂殿。
- 环境：永夜，冷色，唯一不用暖金色的区域。桂树，捣药声。
- 驻场 NPC：太阴星君、嫦娥（**复数**，是月宫仙女的统称，含姮娥仙子、霓裳仙子）、玉兔。

### 1.3 灵霄宝殿的准入规则（重要）

第 7 回原文：悟空「只打到**通明殿里，灵霄殿外**」。他**未曾打进**灵霄宝殿。

本作保留的纪律是：**不能打进去，只能被引进去。** 但也不能简单地放一堵墙。处理如下：

1. **默认**：玩家可以走到灵霄宝殿的**丹墀**上，可以看到殿门大开，可以看到里面的金柱、琉璃盘、珊瑚树，可以看到御座的轮廓。**门口有王灵官**。
2. **王灵官不会打你**（本作无战斗），他只是站在那里，说他那句唯一的台词：「泼猴何往？有吾在此，切莫猖狂。」然后不再说话，也不让开。
3. **进入的唯一方式**：由**四大天师引奏**。玩家在通明殿完成一段"递本子"的流程（这正是原著的正规程序），天师引你入殿，你获得一次与玉帝的正式对话。
4. 这样处理的结果：玩家进得去，但必须**按天庭的规矩**进去。而"按规矩"这件事，本身就是全书对孙悟空最大的考验。玩家会自己咂摸出味道。

**玉帝设定要点**
- 原著**没有**玉帝的正面外貌描写。可用的视觉素材只有仪仗：「**八景鸾舆，九光宝盖**；散宝花，喷真香」（第 7 回）。本作因此把玉帝做成**逆光剪影 + 珠帘后的轮廓**，永不给正面特写。这既忠于原文，又省下一个高精度角色模型。
- 全书玉帝与悟空**只直接对话过两次**（第 4 回封齐天大圣、第 58 回真假美猴王）。本作的灵霄殿对话是第三次，属于合理增补，但必须保持"极简、公文、不动声色"的质感。
- 他的情绪在原著中全部由叙述者代写（"惊讶""大恼""悚惧"），台词本身永远平的。**配音必须压住，不要演**。
- 代表台词：「那孙悟空乃下界妖仙，初得人身，不知朝礼，且姑恕罪。」／「今宣你做个齐天大圣，**官品极矣，但切不可胡为**。」／「依卿所奏。」

**王母设定要点**
- 原著中王母与悟空**全书无一句正面对话**。本作严格遵守：她只在瑶池的最深处远远出现一次，不可接近，不可对话。
- 台词仅两处，都不是对悟空说的：「汝等摘了多少蟠桃？」
- 设计意图：整个天宫你都能走进去、都能搭话，唯独这一个人不理你。这个"唯一的例外"比一百句台词更有效。

**太上老君设定要点**
- 性格弧线在第 39 回被完整写出，只用几句对白：「咄！快去！没有！」→「这泼猴却也缠帐，没有没有，出去出去。」→「去去去！」→（转念）「这猴子惫懒哩，说去就去，只怕溜进来就偷。」→「你这猴子，手脚不稳，我把这还魂丹送你一丸罢。」
- **口硬心软**。对话系统应实现"缠磨"机制：玩家反复追问同一件事，老君的拒绝会逐级软化，最后给你点东西。这是本作唯一一个有"状态机"的 NPC。
- 悟空称他「**老官儿**」。

**太白金星设定要点**
- **本作的向导角色**。他会主动在南天门等你、在你迷路时出现、在你要闯灵霄殿时拦你。
- 原著无本相肖像诗。唯一可靠的视觉符号是第 3 回小猴说的「外面有一老人，**背著一角文书**」——**背着文书**。

- 招牌句式：「**大王息怒。**你自来未曾到此天堂，却又无名，众天丁又与你素不相识，他怎肯放你擅入？**等如今见了天尊，授了仙箓，注了官名，向后随你出入，谁复挡也？**」

**四大天师设定要点**
- 四人是**一个组合**，应设计为可以互相接话的群体对话（本作唯一的多人对话场景）。
- 他们是天庭里唯一会跟悟空开玩笑的一组。第 51 回葛仙翁："猴子是何前倨后恭？" 许旌阳："这猴头还是如此放刁。"
- 考据：道教通行的四大天师是张道陵、葛玄、许逊、**萨守坚**；《西游记》以"丘弘济"替下萨守坚，来历学界无定论。**本作沿用原著的丘弘济，不做考证性发挥**。第 87 回作"丘洪济"，属异文，统一用"丘弘济"。

**王灵官设定要点**
- 全书**仅出现一次**（第 7 回），却是天庭唯一一个正面单挑不落下风的人（"鞭棒往来无胜败"）。
- 本作给他**唯一一句台词**，此后无论玩家说什么，他都沉默。这份沉默就是他的角色。
- 兵器：金鞭。神号：太乙雷声应化尊。

**二郎神设定要点（重点纠错）**

- **狗不叫哮天犬**。"哮天"全书 0 次，原文作「被二郎爷爷的**细犬**赶上」。

- 外貌有全诗（第 6 回），是全书信息量最大的一段角色描写：「**仪容清俊貌堂堂，两耳垂肩目有光。头戴三山飞凤帽，身穿一领淡鹅黄。缕金靴衬盘龙袜，玉带团花八宝粧。腰挎弹弓新月样，手执三尖两刃枪。**」

- 七色**不是彩虹七色**，原文是：**红、青、素、皂、紫、黄、绿**（"素"=白，"皂"=黑）。这是可直接落地的角色配色表。
- 她们是**定时事件**：游戏内每隔一段时间，七人各顶花篮进入蟠桃园摘桃。玩家可以旁观、可以搭话、可以拦。
- **一个值得做文章的叙事细节**：她们回报王母时说悟空"**行凶拷打**"，但原文中悟空只是喝问，并未动手。本作保留这个"罗生门"——玩家亲眼看到自己没动手，之后在瑶池的席间闲谈中会听到"齐天大圣行凶拷打七位仙子"的版本。**不解释，不澄清。**

**卷帘大将 / 天蓬元帅设定要点**
- 这两位此刻**都还在天上**，都还没犯事。这是本作赠送给玩家的一份小小的时间旅行。
- 卷帘大将的天庭履历有全诗（第 22 回），可作为长对话内容：「**南天门里我为尊，灵霄殿前吾称上。腰间悬挂虎头牌，手中执定降妖杖。**」——他此刻仍在这个位置上，站得笔直。
- 时间线疑点（**标注为存疑，不在游戏内断言**）：沙僧打碎玻璃盏的那场蟠桃会与第 5 回被悟空搅乱的那场是否同一场，原著未明言。本作**不做同场处理**，避免自造设定。
- 天蓬元帅在天河，性格已经是后来那个八戒，只是还穿着元帅的甲。

### 2.5 玩家角色：齐天大圣

| 项 | 设定 |
|---|---|
| 自称 | **「老孙」**（全书 618 次）、「我老孙」（58 次）。**绝不用「俺老孙」**——该说法全书 0 次，是戏曲影视的产物 |
| 装束 | 「戴上**紫金冠**，贯上**黄金甲**，登上**步云鞋**」（第 4 回）。三样分别来自西海敖闰（锁子黄金甲）、北海敖顺（藕丝步云履）、南海敖钦（凤翅紫金冠） |
| 兵器 | 如意金箍棒。「两头是两个**金箍**，中间乃一段**乌铁**」，镌「**如意金箍棒，重一万三千五百斤**」。原形「约有斗来粗，**二丈有余长**」，可变绣花针藏耳内 |
| 移动 | 筋斗云。原著「一筋斗十万八千里」——本作不做等比缩放，只做"快得离谱"的手感 |
| 骂人分层 | 毛神 → 泼猴 → 泼毛神 → 业畜 → 脓包 → 亡人 → 猢狲（越骂越低） |
| 敬称带调侃 | 老星（金星）、老官儿（老君）、老太阴（太阴星君）、贤邻（龙王） |
| 三叠短语 | "聒噪，聒噪""好狠，好狠""走，走，走""了帐，了帐"——**配音与字幕不得合并简化**，这是他的情绪节奏 |
| 俗谚库 | 「愁海龙王没宝」「赊三不敌见二」「走三家不如坐一家」「官差吏差，来人不差」「一客不犯二主」「美不美，乡中水」「亲不亲，故乡人」「杀人一万，自损三千」「胜负乃兵家之常」「**今朝有酒今朝醉，莫管门前是与非**」「**皇帝轮流做，明年到我家**」 |

**悟空的语言核心**：他从不用敬语描述天庭机构，而是把神圣事物拉进市井尺度——「养马者，乃后生小辈下贱之役，岂是待我的？」「那玉帝**不会用人**」「就打上灵霄宝殿，教他**龙床定坐不成**」。这套降格修辞是大闹天宫全部喜剧性的语言来源，**是本作对白写作的第一原则**。

**玩家配音**：玩家角色是否配音需要单独决策（见《04-音频设计文档》§6）。默认方案是**配音**，因为本作的乐趣有一半在于"听见自己用这种腔调跟玉帝说话"。

## 3. 对话系统的内容规格

### 3.1 每个 NPC 的内容包

| 层 | 条数 | 说明 |
|---|---|---|
| **招呼语** | 2–3 | 玩家靠近时触发，随机播放 |
| **主题对话** | 3–6 组 | 每组 2–5 轮，围绕一个话题（该 NPC 的职司、与你的过节、天宫的某条设定） |
| **原文彩蛋** | 1–2 | 直接说出他在原著里的名台词，一字不改 |
| **拒绝/敷衍语** | 2–3 | 玩家问超纲问题时的兜底 |
| **告别语** | 1–2 | |
| 合计 | **约 20–35 条** | 主要角色（01–24）走满；杂役层（25–40）取半 |

**不是所有角色都走满。** 三个角色的设定本身限制了条数：

| 角色 | 条数 | 原因 |
|---|---|---|
| **王母娘娘** | **2** | 原著与悟空全书无一句正面对话。本作严守——她只有那两句不对你说的话 |
| **王灵官** | **1** | 全书仅一句台词。此后无论玩家说什么都沉默 |
| **二郎显圣真君** | **6** | 「听调不听宣」，不在天宫。只能在南天门远眺灌江口时由金星转述，外加一段可选的远程问候 |

全场语音条目估算：主要 NPC 21 人 × 28 + 特例 3 人共 9 条 ≈ **597**；杂役层 25 个说话人共 **≈ 224**；玩家侧约 **300**；旁白与系统 **≈ 60**。合计 **≈ 1181**。

> 精确数字以《04》§2 的清单为准；工具链的 `validate` 脚本会做机械核对（《02》§9.3）。

### 3.2 台词写作规则

1. **原文优先**。凡原著有现成台词的地方，一律直接用原文，不改写、不白话化。玩家听得懂——古白话的节奏本身就是氛围。
2. **新写台词必须与该角色的语体特征表一致**（见 §2 各角色"语体"列）。新写台词禁止出现原著不曾有的现代词汇。
3. **不解释设定**。让 NPC 用他自己的立场说话，不要让他变成导游。需要科普的内容走"考据栏"UI（见《03-美术规范》§7），不进台词。
4. **每个 NPC 至少有一句话，是站在他自己的利益上、跟你意见相左的**。天宫不能是一片对你的赞美。
5. **禁止预言**。没有任何 NPC 知道后面会发生什么。玩家知道就够了。

### 3.3 悟空的"缠磨"机制

唯一的对话状态机，只用于太上老君（可扩展至蟠桃园土地、御马监监丞）：

```
玩家反复追问同一话题 →
  第 1 次：断然拒绝    「咄！快去！没有！」
  第 2 次：不耐烦      「这泼猴却也缠帐，没有没有，出去出去。」
  第 3 次：赶人        「去去去！」
  第 4 次：转念（旁白/自语）「这猴子惫懒哩，说去就去，只怕溜进来就偷。」
  第 5 次：给你        「你这猴子，手脚不稳，我把这还魂丹送你一丸罢。」
```

五句全部是原文。这一条完整的性格弧线，是本作证明"原著本身就是好游戏设计"的样板。

## 5. 五个必须统一口径的通行讹误

配音、字幕、UI、美术全部适用。**这是本作最容易被人挑错的地方，也是最容易做出差异化的地方。**

| 通行说法 | 原著实况 | 本作口径 |
|---|---|---|
| 二郎神叫**杨戬** | 全书 0 次。原著只有"父姓杨"（第 6 回"配合**杨君**"）。"杨戬"出自《封神演义》 | 称「二郎显圣真君」「小圣」 |
| **哮天犬** | "哮天"全书 0 次。原文作「二郎爷爷的**细犬**」 | 称「细犬」 |
| 二郎神**三只眼** | "三只眼"全书 0 次，写其目只用"**凤目/凤眼**" | 不画第三只眼 |
| 悟空口头禅**俺老孙** | 全书 0 次。原著一律"**老孙**"(618)／"我老孙"(58) | 只用「老孙」 |
| **五指山** | 全书 0 次。原文作「将五指化作金木水火土五座联山，唤名『**五行山**』」 | 称「五行山」 |

### 5.1 另外三条易错点

- **"齐天大圣"不是悟空自封的**。是**独角鬼王**的建议（第 4 回："大王有此神通，如何与他养马？就做个齐天大圣，有何不可？"），悟空"欢喜不胜，连道几个'好！好！好！'"。本作若有相关台词，须照此。
- **七十二变斗法中"灰鹤"是二郎变的，不是悟空**。悟空的顺序是：麻雀 → 大鹚老 → 鱼儿 → 水蛇 → **花鸨** → 土地庙 → 二郎模样。（本作时间线在此之前，仅供彩蛋台词参考。）
- **镇元子不属天庭**。原著明分"地仙之祖／神仙之宗／天仙（太乙散数）"三级，镇元子走三清道统，与玉帝官僚系统平行。**不要把他放进天宫**。

### 5.2 原著自身的异文（本作择一，并在考据栏注明）

| 项 | 异文 | 本作取 |
|---|---|---|
| 老君金丹容器 | 第 5 回「五个葫芦」／第 7 回「五壶丹」 | **五个葫芦**（第 5 回是现场描写） |
| 二郎神战绩 | 第 6 回观音语「力诛六怪」／同回赞诗「力诛八怪」 | 不在台词中出现具体数字 |
| 丘弘济 | 第 51 回「丘弘济」／第 87 回「丘洪济」 | **丘弘济** |
| 化乐宫 | 繁体本作「花樂宮」／简体本作「化乐宫」 | **化乐宫** |

### 5.3 原著明确无载、本作必须自拟并标注的内容

**这份清单必须完整**——它决定了考据栏的可信度。凡下列内容出现在游戏中，考据栏须标注「本作设定」。

**人物**
- 玉皇大帝、王母娘娘、太白金星本相的**正面外貌**——原著三者均无描写
- **四值功曹**的四位具体名号（原著仅作"四值功曹"，从未列名）。本作只用「**值日功曹**」这一原著出现过的写法，**不生造另外三位**
- 第 7 回护驾的"天蓬"与八戒前身"天蓬元帅"是否同一，原著无交代。本作**不做关联**

**空间**
- **五层分层结构**本身——原著对天宫空间没有系统交代，分层是本作的组织方式
- **披香殿**的建筑外观（原著只有"侍香玉女"一句）
- **东天门、北天门**（西天门有第 5 回原文依据，东、北无）
- **天河渡口**的形貌（原著只说天蓬"掌管天河八万水兵"）
- 三十三宫七十二殿中**未被原著命名的 95 座**及其布局

**装置与交互**
- 瑶池的**席位牌**
- 斗牛宫的**点卯名牌墙**
- 通明殿**案上可读的表章**
- 灵霄宝殿的**引奏准入流程**（原著有"天师引奏"的程序，但玩家进殿是本作增补）
- 千里眼、顺风耳**驻南天门门楼兼作教学提示**
- 李天王**用照妖镜照玩家**
- 朝圣楼的**金钟天鼓可敲**（原著只写"金钟撞动""天鼓鸣时"，未写谁敲、能否敲）

**弃用**
- 「彩门」「玉阶」二词在天宫语境中**查无出处**，疑为影视改编产物。本作弃用，改称「朱门」「玉户」「丹墀」
