## 0. 美术总纲

### 0.1 一句话

**明代皇家宫殿的骨架，道教宫观的符号，佛教三十三天的宇宙尺度——三者叠在云上，用金、白、青三色说话。**

这不是我的概括，这是《西游记》自己的做法。吴承恩把明代紫禁城的朝仪与营缮制度，装进道教宫观的名号与符号里，再罩上佛教的天层宇宙。美术只要老实照做就行。

### 0.2 现实中的最佳参考原型：武当山金殿

**明永乐十四年（1416）建，天柱峰顶，海拔 1612 m。铜铸鎏金仿木结构，用铜 20 万斤、黄金 2000 斤，构件分体铸造、榫卯组装、通体鎏金，无铸凿之痕。面阔三间 5.8 m，进深三间 4.2 m，高 5.54 m，重檐庑殿顶。**

这是中国现存等级最高的铜铸鎏金建筑——**一座道教殿堂用了与太和殿同级的重檐庑殿顶**。

它是《西游记》成书年代真实存在的"人间天宫"：明永乐朝以皇家最高规制建造的道教神殿，坐落在山巅云海之上。

**结论：灵霄宝殿的材质与气质照武当金殿做（鎏金铜，山巅，云海），尺度与仪轨照太和殿做。** 不要做成一座刷了金漆的木构彩画建筑——那是明清宫殿，不是天宫。

### 0.3 三条判据

任何一张截图，问三个问题：

1. **它像不像明代的？** —— 斗拱密而小，屋顶举架平缓，庑殿顶，黄琉璃，须弥座。（判据见 §1）
2. **它在不在云上？** —— 画面里必须有云。地平线不能是地面，只能是云海或虚无。（判据见 §3）
3. **它有没有"气"？** —— 光要能看见（体积光），空气要有颜色（雾），要有东西在飘（粒子、飘带）。（判据见 §4）

三条全中，才叫"仙气飘飘"。少一条都会变成"游戏里的中式建筑"。

## 1. 建筑形制规范

### 1.1 屋顶等级序列

由高到低（清式规制，明代大体相同）：

```
重檐庑殿 > 重檐歇山 > 重檐攒尖 > 单檐庑殿 > 单檐歇山 > 单檐攒尖 > 悬山 > 硬山 > 盝顶
```

> 各家排序在"攒尖"的插入位置上略有出入，属通说而非唯一定论。

| 屋顶 | 脊数 | 特征 | 本作用于 |
|---|---|---|---|
| **庑殿**（宋称四阿） | 5（一正脊 + 四垂脊） | 四面坡，无山花。明清仅皇家与孔庙可用 | 灵霄宝殿、通明殿、天王殿等主轴大殿 |
| **歇山** | 9（一正脊 + 四垂脊 + 四戗脊） | 带山花 | 次级殿宇、朝圣楼、斗牛宫 |
| **攒尖** | 无正脊 | 顶端置宝顶。亭、阁、塔 | 蟠桃园的亭、寿星台、灵霄宝殿的收头 |
| **悬山 / 硬山** | 2 | 硬山不出山墙，用青板瓦，**不得用筒瓦、更不得用琉璃瓦** | 御马监、力士值房等杂役建筑 |

### 1.2 太和殿基准数据（比例尺锚点）

所有建筑的尺度以此为基准换算。

| 项 | 数据 |
|---|---|
| 面阔 | 现存 **十一间**，64.24 m。**明代奉天殿为九间** |
| 进深 | 五间，37 m（合计 55 间） |
| 建筑面积 | 2377 ㎡ |
| 殿身高 | 26.92 m |
| **通高（含台基）** | **35.05 m** |
| 台基 | **三层汉白玉须弥座**（"三台"），高 **8.13 m** |
| 屋顶 | 重檐庑殿，黄琉璃瓦 |
| 正吻 | 高 **3.4 m**，重约 **4.3 吨**，13 块二样黄琉璃脊件拼成，现存最大 |
| 脊兽 | **10 个 + 骑凤仙人**（全国唯一） |
| 殿内柱 | 72 根，径约 1 m；御座周围 6 根沥粉贴金蟠龙金柱 |
| 藻井 | 八角浑金蟠龙衔吊珠，垂珠俗称"轩辕镜" |

**本作取九间**（明代奉天殿制），因为《西游记》是明代小说。现存太和殿的十一间是康熙三十四年（1695）重建后的形制，一说与防火及大木料短缺有关。

### 1.3 脊兽等级阶梯

顺序（太和殿）：**龙、凤、狮子、天马、海马、狻猊、狎鱼、獬豸、斗牛、行什**，前置骑凤仙人。

| 建筑 | 脊兽数 |
|---|---|
| 太和殿 | **10**（全国唯一的偶数，且唯一有"行什"） |
| 保和殿、乾清宫 | 9 |
| 中和殿 | 7 |
| 王府、寺庙 | 5–7 |
| 普通建筑 | 1–3 |

**规则：除太和殿外一律为奇数，且不超过 9。**

本作映射：**灵霄宝殿 10 兽 + 骑凤仙人**（全场唯一）；通明殿 9；主轴其他殿 7；外围 5；杂役建筑 3。

### 1.4 台基与栏杆

- 三大殿共用工字形"三台"，台面总面积约 25000 ㎡。
- 望柱约 1460 根（一说 1480），栏板约 1415 块（一说 1414），**螭首（龙头）1138–1142 个**。各家统计口径不一——**建模取整数级即可，考据栏中用"一千一百余个龙头"这样的模糊表述，不报死数**。
- **螭首同时是排水口**，雨季形成"**千龙吐水**"。本作**不做天气系统**，把它做成**每游戏日一次的定时奇观**（见《01》§4）。
- **须弥座**源自佛教须弥山（世界中心圣山）。标准分层自下而上：圭角—下枋—下枭—束腰—上枭—上枋。（通行做法，**待核实**具体文献。）

### 1.5 丹陛（月台）陈设

正殿前的宽阔平台，标准陈设：

| 物件 | 数量 | 象征 | 本作用法 |
|---|---|---|---|
| **日晷** | 1 | 授时之权 | 灵霄殿前。指针的影子随「**游戏日**」（18 分钟的抽象周期，见《01》§4）移动。<br>⚠️ 这与 §5.1「不做昼夜循环」是**刻意的不一致**：太阳固定在朝晖预设，只有日晷的影子在走。天宫的时间是仪式性的，不是物理性的 |
| **嘉量** | 1 | 度量衡之权 | 灵霄殿前 |
| **铜龟、铜鹤** | 各 1 对 | 长寿 | **内部中空，大典时燃檀香出烟**——这是极好的 3D 动效点，朝会事件时龟鹤口中冒烟 |
| **丹陛石 / 御路石** | 1 | | 太和殿御路石雕九条蟠龙及祥云、海水江崖 |

### 1.6 华表

- 天安门前后各一对，明永乐十八年建，通高 **9.57 m**，径 **0.98 m**。
- 构成：须弥座柱础 → 蟠龙柱身 → 横插云板 → 承露盘 → 蹲兽「**犼**」。
- 前对面南名「望君归」，后对面北名「望君出」。
- **道教宫观的华表多为八角柱体，浮雕祥云或八卦，而非皇家的圆柱云龙。** 本作：南天门内用皇家式（圆柱云龙），兜率宫用道教式（八角八卦）。

### 1.7 琉璃瓦色等级

```
黄（帝王专用） > 绿（王公、亲王府邸、寺庙道观） > 蓝（祭天建筑） > 黑（藏书处，取水克火）
```

- 明代前期：主要建筑满铺黄琉璃，次要建筑绿瓦或**黄瓦绿琉璃剪边**；明后期宫殿基本满铺黄琉璃。
- **本作用瓦色做距离分级**：主轴与内苑满铺黄琉璃；外围宫殿海用**黄瓦绿剪边**；再外围纯绿瓦。这样玩家从空中一眼就能读出"哪里是中心"。
  → 数据模型须支持三档：`tileColor: 'huang' | 'huang-lv-jianbian' | 'lv' | 'lan' | 'hei'`（《02》§3.1）。"剪边"是屋面主体用黄瓦、檐口与脊部镶一圈绿瓦的做法，实现上是给屋面 UV 边缘区域换一套材质参数，不需要额外几何。
- 兜率宫（道教）用**绿琉璃**，广寒宫用**蓝/银灰**，这两处刻意脱离黄色系。

### 1.8 斗拱

- 清式以"**攒**"计数，按"**踩**"分级。最简为一斗三升（无踩），最繁十一踩。紫禁城午门、太和殿实际用九踩单翘三昂（此说来自二手技术资料，**待核实**）。
- 等级越高 → 攒数越多、出踩越多、装饰越繁。
- **明代关键特征：斗拱较宋元显著变小、排列变密、结构性减弱而装饰性增强。**

> **这是做出"明代感"最重要的一条细节**：斗拱要**密而小**，像檐下一条精细的花边；不要做成唐宋那种硕大疏朗、一攒一攒看得清清楚楚的样子。做错了，整座建筑会瞬间变成唐风，与《西游记》的年代感脱节。

### 1.9 其他等级符号

- **面阔间数以九、五为尊**（"九五之尊"）。
- **门钉**：宫门九路九排 = 81 颗为最高级。原文「**金钉攒玉户**」正对应此。

### 1.10 道教 vs 皇家：本作如何混

| 要素 | 皇家宫殿 | 道教宫观 | 本作 |
|---|---|---|---|
| 华表 | 圆柱，雕云龙 | 八角柱，浮雕祥云或八卦 | 主轴用皇家，兜率宫用道教 |
| 瓦色 | 黄琉璃 | 绿琉璃或绿剪边，唯敕建可用黄 | 见 §1.7 |
| 屋顶 | 重檐庑殿为尊 | 多歇山、攒尖，高阁常用多重檐 + 宝顶 | 灵霄宝殿混合（见下） |
| 装饰母题 | 龙凤、海水江崖、五爪龙 | **太极、八卦、云纹、仙鹤、日月、灵芝、松鹤龟鹿、二十八宿** | 主轴用龙凤，内苑与兜率宫用道教母题 |
| 正殿性质 | 御座（人间权力） | 神像（神格空间） | 灵霄宝殿是御座——这一点忠于原著 |

### 1.11 灵霄宝殿的形制矛盾（必须知道的一处）

原文明写：「**三檐四簇**」「**大金葫芦顶**」。

"葫芦顶"是**攒尖顶宝顶**的做法，不是庑殿正脊。也就是说，**吴承恩想象中的灵霄宝殿更接近多重檐攒尖阁**（天坛祈年殿、道观高阁那一路），而不是太和殿式的重檐庑殿正殿。

这是原著与现实规制之间最值得做文章的一处张力。

**本作方案**：重檐庑殿的**体量与仪轨**（三层须弥座、九间面阔、10 脊兽、九路门钉）+ 攒尖**金葫芦顶的收头**（在庑殿顶之上再起一层攒尖小阁，顶置大金葫芦）。这是一个原著里有、现实里没有的建筑——而这正是它该有的样子。**在考据栏中说明这个取舍。**

## 2. 配色体系

### 2.1 主色板

| 名称 | 十六进制 | 用于 |
|---|---|---|
| **金阙金** | `#E8B455` → 高光 `#FFF0C4` | 鎏金铜、金顶、金葫芦、法宝 |
| **琉璃黄** | `#D99B2B` / 釉面高光 `#FFE9A8` | 黄琉璃瓦 |
| **朱门红** | `#A82F26` | 宫门、柱、栏杆内侧。**用量要克制**，天宫不是宫墙红的紫禁城 |
| **汉白玉** | `#EDE8DC` / 阴影 `#B9B4AC` | 须弥座、栏杆、丹陛、望柱 |
| **瑞气紫** | `#8B6FB0` → 淡 `#C9B8E0` | 雾、远景、阴影侧的空气 |
| **碧雾青** | `#5E8C9E` → 淡 `#A9CBD6` | 云海阴影、逆光边缘、远山 |
| **琼香白** | `#F5F2EA` | 云、烟、光晕 |
| **月宫银** | `#8FA4B8` / 冷高光 `#D6E4F0` | 广寒宫专用，全场唯一的冷色区 |
| **丹炉赤** | `#D4471F` | 兜率宫炉火、八卦炉，唯一的高饱和暖点 |
| **蟠桃粉** | `#E8A0A8` / 果实熟色 `#C9433F` | 蟠桃园的花与果 |

> **色彩空间**：上表 hex 均为 **sRGB**。在 HDR + AgX 管线里，材质 `color` 必须以 sRGB 载入（`SRGBColorSpace`），由引擎转 linear 参与计算；而 shader 里手写的常量必须**自己转 linear**（`pow(c, 2.2)` 或 `THREE.Color.setStyle` 后取值）。**这一步搞错，所有颜色都会偏。**

### 2.2 配色来自原文

配色不是设计师定的，是原文定的：

| 原文 | 出处 | 色彩指令 |
|---|---|---|
| 「**金光万道滚红霓，瑞气千条喷紫雾**」 | 第 4 回 | **金 + 红霓 + 紫雾**。这是天宫的官方色卡。注意"紫雾"——天宫的雾是紫的，不是白的 |
| 「碧沉沉，琉璃造就；明幌幌，宝玉妆成」 | 第 4 回 | 南天门是**碧色琉璃**，不是黄的 |
| 「**明霞幌幌映天光，碧雾蒙蒙遮斗口**」 | 第 4 回 | **暖霞在上，碧雾在下**。这一句直接定义了本作的垂直色彩梯度 |
| 「琼香缭绕，**瑞霭缤纷**，瑶台铺彩结，宝阁散氤氲」 | 第 5 回 | 瑶池是**多彩的**，不是单色。彩结、氤氲 |
| 「**一天瑞霭光摇曳，五色祥云飞不绝**」 | 第 5 回 | 祥云是**五色**的，不是白的 |
| 「**紫巍巍，明幌幌，圆丢丢，亮灼灼**，大金葫芦顶」 | 第 4 回 | 金顶是**紫中透亮**——鎏金在紫雾里的反光 |

### 2.3 垂直色彩梯度（全场最重要的一条美术规则）

依据「明霞幌幌映天光，碧雾蒙蒙遮斗口」：

```
 高 ┃  第五层 兜率宫    冷金 + 高对比 + 空气稀薄      饱和度低，对比高
    ┃  第四层 广寒宫    银蓝冷色（唯一的冷区）
    ┃  第三层 内苑      暖金 + 桃粉 + 琼香白          饱和度最高，最"甜"
    ┃  第二层 宫城      正金 + 朱红 + 汉白玉          标准
    ┃  第一层 天门      暖霞（逆光）
 低 ┃  云海之下         碧雾青 + 紫雾，能见度极低      饱和度低，对比低
```

**玩家往上飞，画面逐渐变冷、变清、变空；往下沉，逐渐变暖、变浊、变闷。** 这个梯度让飞行本身产生叙事。

### 2.4 色调映射与分级

- **Tonemap 用 AgX**（不用 ACES）。理由：ACES 会把高饱和的金色推向橙红并快速去饱和，天宫会显脏。AgX 的高光过渡更中性，金色能保持金色。
- 全场统一走一张 **32³ 3D LUT**，给调色一个总闸门。
- **禁止**：全局降饱和的"电影感"调色。天宫是明亮、饱和、华丽的。灰蒙蒙的天宫是设计失败。

## 3. 云

云是这个项目的地面、天空、和一半的氛围。**没有云就没有天宫。**

### 3.1 云的三个功能

| 功能 | 实现层 | 判据 |
|---|---|---|
| **当地面** | 中景体积云 / 分层平面 | 玩家往下看，看到的是翻涌的云顶，不是空气 |
| **当遮挡** | 覆盖度贴图控制的云洞 | 宫殿群在云中若隐若现，永远看不全 —— **"看不全"就是仙气** |
| **当速度感** | 近景 billboard 云絮 | 飞行时有东西掠过镜头 |

### 3.2 云的形态规范

- **不要积雨云。** 天宫的云是**层积状 + 丝缕状**的混合：底部平坦如海，顶部有缓慢隆起，边缘拉出丝缕。参考实景：**黄山云海、武当山日出云海**。
- **不要灰色。** 云的暗部是**碧雾青偏紫**，亮部是**琼香白偏暖金**。逆光时边缘要有强烈的**金色轮廓光**（这是"祥云"最重要的特征）。
- **"五色祥云"的处理**：不是把云涂成五种颜色，而是让云在**不同角度呈现不同颜色**——用较强的相位函数（Henyey-Greenstein g≈0.6）让前向散射偏金、侧向散射偏紫、背向偏青。物理上正确，观感上正是"五色"。
- **速度**：极慢。云的整体漂移应该慢到玩家察觉不到，只有站着不动看 30 秒才发现它在动。快速滚动的云 = 廉价感。

### 3.3 云洞（Coverage Map）

**这是让整个场景"成立"的关键工具。**

一张手绘的 2D 覆盖度贴图，控制天宫上空哪里有云、哪里露出。用它来：

- 让灵霄宝殿的金顶**永远露在云上**（远远就能看到，成为导航地标）
- 让宫殿海**半沉在云里**（做出"三十三宫七十二殿"的无限感，同时省掉 90% 的几何）
- 在蟠桃园上方开一个洞，让阳光**直射下来**（园子是暖的、亮的、可爱的）
- 在斩妖台上方压厚云，那一片**常年阴着**

美术直接改这张图就能重构整个场景的观感，不需要动代码。**这是本项目性价比最高的一个工具。**

### 3.4 蟠桃园的云

原文：「左右楼台并馆舍，**盘空常见罩云霓**」。

园子在云上，且**常年被云霓笼罩**。处理：园子四周有一圈低矮的、缓慢流动的**彩色云带**（这就是"云霓"——虹霓般的云），把园子和外界隔开。玩家进园的瞬间穿过这层云带，光线和音乐同时切换。

## 4. 仙气四件套

除了云，还有四样东西构成"仙气"。缺一样，画面就"不仙"。

### 4.1 可见的光（体积光 / 丁达尔效应）

**判据：画面里必须能看见光柱。** 不是被照亮的物体，是光本身。

| 位置 | 光源 | 形态 |
|---|---|---|
| 南天门 | 门外的天光 | 从门洞射入的巨大平行光柱，尘埃在其中浮动 |
| 主轴宫殿海 | 太阳 | 云洞漏下的巨型光束，缓慢移动 |
| 灵霄宝殿内 | 高窗 | 斜射光柱落在金柱上 |
| **披香殿** | 香烟 + 高窗 | **全场最浓的丁达尔效应**，几乎看不清对面 |
| 兜率宫 | 炉火 | 从八卦炉向上的暖光柱，与冷空气对比 |
| 广寒宫 | 月 | 冷蓝光柱，稀薄，与其他区域形成对照 |

技术实现见《02》§5.3。

### 4.2 有颜色的空气（雾）

**判据：画面深度必须靠雾读出来，不能靠透视。**

- 三层深度的雾色必须不同（见 §2.3）。
- **太阳内散射必须做**：朝太阳看时空气偏暖偏亮，背对时偏冷偏暗。这一条决定了"空气感"的成败。
- 雾浓度：站在灵霄殿丹墀上望向南天门（约 800 m），南天门应该**只剩一个金色的剪影**，细节全部被雾吃掉。

### 4.3 飘动的东西

**判据：画面静止 3 秒，必须有至少 3 样东西在动。**

| 元素 | 密度 | 速度 | 说明 |
|---|---|---|---|
| **灵光浮尘** | 全场常驻，3000–8000 | 极慢，布朗运动 | 逆光时才明显。这是"空气里有灵气"的直接表达 |
| **飘带 / 天衣** | NPC 身上、幢幡上 | 缓慢波动 | 见 §4.4 |
| **幢幡** | 殿前、朝会时 | 风摆 | 原文「宝节幢幡瑞气飘」（第 7 回） |
| **桃花瓣** | 蟠桃园 | 缓慢飘落 | 原文「时开时结」，所以永远有花在落 |
| **香烟** | 披香殿、丹炉、龟鹤 | 上升 + 涡旋 | |
| **云絮** | 飞行时 | 随速度 | |
| **仙鹤** | 远景，偶尔 | 滑翔 | 原文「白鹤声鸣振九皋」（第 5 回）。远景 billboard 即可 |

### 4.4 飘带（流光）

天宫的动态母题。三种：

| 类型 | 形态 | 技术 |
|---|---|---|
| **天衣飘带** | NPC 肩上/臂间的长绸，随移动摆动 | 沿骨架的 ribbon geometry，顶点着色器里做正弦波 + 噪声扰动 |
| **祥云流光** | 空中缓慢游走的光带，无始无终 | 沿一条 Catmull-Rom 曲线生成 ribbon，UV 滚动 + 加法混合 + bloom |
| **幢幡** | 竖直悬挂的旗，风摆 | 平面网格 + 顶点波动 |

**流光的作用**：把空旷的宫殿间距填满。天宫很大很空，几条缓慢游走的光带能让"空"变成"辽阔"，而不是"没做完"。

### 4.5 反面清单：什么会毁掉仙气

| 禁止 | 原因 |
|---|---|
| 灰色的雾 | 天宫的雾是紫的、青的、金的 |
| 快速滚动的云 | 廉价感 |
| 全局降饱和调色 | 天宫是华丽的 |
| 硬边阴影 | 用软阴影 + 大量间接光 |
| 完全看得清的场景 | 看不全才是仙气。永远保留 20% 被云雾遮住 |
| 空无一物的天空 | 至少要有云、光柱、飞鹤中的一样 |
| 死板的对称构图 | 建筑对称，但云、光、雾必须打破对称 |
| 纯白的高光 | 金属高光应偏暖金，玉石高光应偏冷白 |
| 现代感的 UI 字体 | 见 §8 |

## 5. 光照

### 5.1 主光

一盏 `DirectionalLight` 模拟太阳，**低角度**（15°–30° 高度角）。

理由：低角度太阳给出长阴影、强逆光、金色轮廓光——这三样是"神圣感"的全部来源。天宫应该永远处在**日出后一小时或日落前一小时**的光照条件下。

**不做完整昼夜循环。** 只做三个预设：

| 预设 | 太阳高度 | 色温 | 用于 |
|---|---|---|---|
| **朝晖**（默认） | 22° 东南 | 3800K 暖金 | 主要状态 |
| **正午**（可选） | 65° | 5500K | 玩家手动切换，看清建筑细节用 |
| **月夜** | 无太阳，月光 | 8000K 冷蓝 | 广寒宫层强制，其他层可选 |

### 5.2 间接光

- 环境光来自 §5.1 的程序化天空 cubemap（IBL）。
- **额外加一盏来自下方的"云海反光"**：一个朝上的半球光，颜色取云海的亮部色。这一盏让建筑的底面、檐下、须弥座侧面不至于全黑。
- 天宫**没有真正的暗部**。最暗的地方也应该有 15% 左右的亮度。这是"仙境"和"地牢"的区别。

### 5.3 阴影

- 主光用 **CSM（级联阴影）**，3 级，最远 300 m。300 m 外靠雾遮掉。
- 阴影必须**软**。PCF 半径要大，宁可糊也不要硬边。
- **接触阴影（contact shadow）** 值得单独做一遍屏幕空间的——柱子和台基交接处如果没有暗角，整个建筑会"浮"起来。

### 5.4 自发光

金顶、法宝、灯、灵光、丹炉走**单独的 emissive 通道**，只对它们做 selective bloom（见《02》§5.6）。

原因：如果对整个画面做 bloom，金色的琉璃瓦会整片糊掉，天宫变成一团光斑。只让"该发光的东西"发光。

## 6. 影视与游戏参考的取舍

| 参考 | 特点 | 本作取 | 本作不取 |
|---|---|---|---|
| **《大闹天宫》动画（1961，上美影）** | 装饰性极强的平面化设计，京剧脸谱，敦煌与年画的色彩，线条造型 | **色彩关系**（金红青的大胆撞色）、**云的装饰性形态**（如意云头） | 平面化、无透视的构图 |
| **86 版《西游记》电视剧** | 干冰烟雾 + 逆光 + 大量金色，预算有限但氛围经典 | **"仙气 = 可见的雾 + 逆光"这个朴素判断**——它其实是对的 | 布景的简陋感 |
| **《黑神话：悟空》** | 高保真写实、材质极精、光影厚重，天庭段落宏大冷峻 | **建筑体量感**、**材质的物理正确** | 整体偏暗偏沉的调性——本作要明亮华丽 |
| **故宫实景** | 形制的唯一真理来源 | **一切形制细节** | 红墙的封闭感（天宫要开阔） |
| **武当山金殿** | 明代皇家道教建筑巅峰 | **灵霄宝殿的材质与气质** | — |

**一句取舍原则**：形制照故宫，材质照武当，色彩照 61 版动画，氛围照 86 版电视剧，精度照黑神话。

## 7. 人物造型规范

技术方案见《02》§8.2：NPC 用**程序化生成的简化人形**，不做骨骼动画、不引入外部角色模型。这不是妥协，是风格选择——**把神仙做成"仙气朦胧的轮廓"，比做成低精度的人像好得多。**

### 7.1 通用规格

| 项 | 规格 |
|---|---|
| **比例** | 7.5 头身（略高于写实的 7 头身）。神仙要比人"长" |
| **构造** | 袍服 = 参数化的圆锥/圆台 + 褶皱噪声；头 = 一个球 + 冠；手 = 简化的袖口，**不做手指**；脚 = 不可见（袍服及地） |
| **面部** | **不做五官细节**。做一个受光的浅浮雕轮廓 + 一对眼位的暗区。距离 3 m 内也只是"看得出有脸"的程度 |
| **边缘** | 所有 NPC 加**一层极薄的菲涅尔轮廓光**（暖金），这是他们"发光"的来源，也是在复杂背景里保持可辨识的手段 |
| **说话动画** | 头部微幅点动（±3°，随语音包络驱动）+ 袖袍顶点动画 + 轮廓光的呼吸式明暗 |
| **待机动画** | 极缓慢的呼吸位移 + 飘带波动。**不做走动**，所有 NPC 站定不移 |
| **三角面预算** | 主要 NPC ≤ 3000 tri；杂役 ≤ 1200 tri；群众用 InstancedMesh，≤ 400 tri |

### 7.2 服色分级（原文依据）

第 4 回朝圣楼段落给出了天庭百官的标准朝服：

> 「**绛纱衣**，星辰灿烂；**芙蓉冠**，金璧辉煌。**玉簪珠履，紫绶金章**。」

| 层级 | 冠 | 衣 | 佩 |
|---|---|---|---|
| **玉帝** | 十二旒冕（本作只做逆光剪影 + 珠帘轮廓，永不给正面特写——原著无外貌描写，见《01》§2.1） | 玄色衮服 | — |
| **上仙 / 大臣**（三清、四御级、四大天师、赤脚大仙） | **芙蓉冠** | **绛纱衣**（深红） | **紫绶金章**、玉簪珠履 |
| **星官**（九曜、二十八宿） | 星冠（冠上有星宿标记） | 各按五行本色 | 玉带 |
| **武将**（李天王、四大天王、巨灵神、天丁） | 金盔 | 明光铠 + 战袍 | 虎头牌、兵器 |
| **仙女**（七衣仙女、嫦娥、玉女） | 双鬟 / 花冠 | **按本色**，见下 | 天衣飘带 |
| **杂役**（力士、道人、童子） | 幞头 / 总角 | 素色短褐 | — |

### 7.3 三个有原文全诗的角色（必须照做）

原著给了三位角色完整的肖像诗，这是白送的建模文档，不用可惜。

**哪吒三太子**（第 4 回）
> 「**总角才遮顖，披毛未盖肩**。神奇多敏悟，骨秀更清妍。诚为天上麒麟子，果是烟霞彩凤仙。龙种自然非俗相，妙龄端不类尘凡。**身带六般神器械**，飞腾变化广无边。」

落地要点：**总角**（两个童子发髻，刚够遮住囟门）、**披毛未盖肩**（头发短，没到肩）——这是一个**真正的孩子**的形象，不是少年。六般兵器全部挂在身上：斩妖剑、砍妖刀、缚妖索、降妖杵、绣毬儿、火轮儿。

**二郎显圣真君**（第 6 回）
> 「**仪容清俊貌堂堂，两耳垂肩目有光。头戴三山飞凤帽，身穿一领淡鹅黄。缕金靴衬盘龙袜，玉带团花八宝粧。腰挎弹弓新月样，手执三尖两刃枪。**」

落地要点：**三山飞凤帽**、**淡鹅黄**袍（不是白袍！）、缕金靴、盘龙袜、玉带、**新月形弹弓**挂腰、三尖两刃枪。
⚠️ **不画第三只眼**（见《01》§5）。原著写他的目只用"凤目"。若美术强烈需要，须在考据栏注明"此为后世通行形象"。

**卷帘大将**（第 22 回）
> 「**腰间悬挂虎头牌，手中执定降妖杖。头顶金盔晃日光，身披铠甲明霞亮。**」

落地要点：**虎头牌**（腰间）、降妖宝杖、金盔、明光铠。他此刻还在灵霄殿前站得笔直。

### 7.4 辨识度策略

40 个 NPC 全部是简化人形，靠什么区分？按优先级：

1. **轮廓**（最重要）——冠的形状、袍的宽窄、有无铠甲、是否持械。远处只看得见剪影时，这是唯一的信息。
2. **色**——服色分级 + 个体主色。同一区域内的 NPC 主色必须拉开。
3. **高度**——玉帝 > 天王/武将 > 上仙 > 仙女 > 童子。可以夸张，天宫本来就不写实。
4. **标志物**——太白金星**背着文书**（第 3 回"背著一角文书"，全书唯一的视觉符号）、李天王托塔、哪吒火轮、二郎持三尖两刃枪、玉兔捧捣药杵。
5. **动态**——飘带的长度与摆幅。上仙飘带最长最慢，杂役几乎没有。

## 8. UI 与文字

### 8.1 字体

- 正文与字幕：**思源宋体（Source Han Serif，SIL OFL 开源）**。**不用黑体**——黑体会瞬间把画面拉回现代。
- 匾额与地名：楷书或隶书，仿匾额的金底黑字或蓝底金字。
  ⚠️ 商业楷体（方正、汉仪等）需授权。若预算不足，用**霞鹜文楷**（开源）或思源宋体加粗替代。
- 数字与英文：只在开发期出现，正式版本不显示任何拉丁字符。

**必须做字体子集化。** 中文全集 Web 字体 5–10 MB，而总资源预算是 40 MB（《02》§0）。

```
构建步骤（tools/subset-font.ts）：
  1. 扫描 content/**/*.yaml + *.json，提取全部出现过的汉字 → 用字表
  2. pyftsubset 按用字表裁剪思源宋体 → woff2
  3. 匾额字体单独裁一份（用字量极小，几十个字）
预期：正文子集 ≈ 400–700 KB，匾额子集 ≈ 30 KB
```

**资源预算分解（40 MB 内，不含语音）**

| 项 | 预算 |
|---|---|
| JS bundle（three + 业务代码，gzip 后） | 8 MB |
| 字体子集（正文 + 匾额） | 0.8 MB |
| 噪声贴图、LUT、覆盖度贴图 | 3 MB |
| 斗拱/瓦垄的 LOD1 法线与 AO 图集 | 6 MB |
| impostor 图集（远景宫殿） | 8 MB |
| BGM（3 层 stem + 6 首场景曲，Opus） | 10 MB |
| 环境音与音效 | 3 MB |
| 余量 | 1.2 MB |

### 8.2 UI 风格

- **极简，不做拟物边框。** 云纹装饰只用一条极细的描边，不做整圈花纹（会显廉价）。
- 对话框：半透明深色底 + 一条金线，宋体白字。**不用气泡框。**
- 所有 UI 元素**渐显渐隐**，不做弹出动画。
- 常驻 UI 只有：一个极简的方位指示、一个当前区域名。**其余全部隐藏，靠交互唤出。**

### 8.3 考据栏

本作从"技术演示"变成"文化产品"的那一层。

- 一个可折叠的右侧栏，默认收起。
- 内容：当前区域/角色/台词的原著出处、原文引用、形制说明、**本作的自拟与取舍说明**。
- 视觉：模仿古籍页面——竖排（可选）、宋体、朱笔批注色标注出处。
- **凡是本作自拟的内容，必须在此明确标注"本作设定"**（清单见《01》§5.3）。这是对读者的诚实，也是这个项目的品格所在。

## 9. 关键场景的画面目标

用文字描述每个场景"做对了应该长什么样"。这是验收判据。

> 这些描述是**方向**，不是可测指标。每个场景在开工时须配 1–2 张参考图（实景照片或概念图）钉在项目墙上，作为真正的比对基准。

### 齐天大圣府（开局第一眼）
> 玩家睁眼的第一个画面。一座**崭新的、气派的、空的**府邸院落。刚落成不久，木料还新，金漆还亮，一切都很得体——玉帝给足了面子。院中一张案，上面摆着五斗星君送来的**御酒二瓶、金花十朵**，没动过。两侧廊下挂着两块匾：**「安静司」**「**宁神司**」，各站着一位仙吏，见你出来就行礼。院子四周是彩色云霓，园外是蟠桃园的桃花。阳光很好。
> **玩家应该觉得这地方挺不错，然后看清那两块匾，然后明白过来。**

### 披香殿（技术展示点）
> 全场**体积光最浓**的房间。终年焚香，殿内几乎看不清对面。高窗斜射进来的光被香烟切成一道道实体般的光柱，尘埃在其中缓慢翻滚。侍香玉女的身影在烟里若隐若现。地面看不见，脚下是一层平铺的白雾。声音也是闷的（混响短、高频被吸掉）。
> **玩家应该下意识地放慢移动速度。**

### 通明殿（社交中枢）
> 全场人最多、最有生气的地方。四大天师围着一张长案，案上堆满各路神仙的表章。他们一边办事一边互相打趣。引奏仙童和传言玉女在旁边跑来跑去。光线是明亮的、均匀的，不做戏剧性的明暗——这是办公室，不是圣殿。殿门朝北开着，能望见灵霄宝殿的丹墀和王灵官的背影。
> **玩家应该想在这里多待一会儿，听他们说话。**

### 南天门（第一印象）
> 逆光。巨大的碧色琉璃门楼占据画面 2/3，细节全在剪影里。门洞中射出的天光是一道实体般的光柱，无数灵光浮尘在其中缓慢上升。两侧的天丁只是更暗的剪影，枪戟的尖端有一点金色反光。门外是无边云海，下界隐约可见。**玩家应该感到自己很小，同时感到门是开着的。**

### 主轴宫殿海（规模震撼）
> 从高空俯瞰。金色屋顶如海浪般延伸到雾中消失，看不到尽头。云在殿宇之间穿行，一半的建筑只露出屋脊。一道巨型光束从云洞落下，缓慢扫过宫殿群。远处灵霄宝殿的金葫芦顶高出云层，是画面里唯一清晰的亮点。**玩家应该数不清有多少座殿，并且放弃数。**

### 灵霄宝殿（威压）
> 仰视。三层汉白玉须弥座层层收进，望柱与螭首排成整齐的行列。九间面阔的鎏金铜殿身在三重檐之上又起一座攒尖金葫芦顶。殿门大开，里面深不见底，只有金柱的反光和琉璃盘、珊瑚树的轮廓。丹墀上日晷的影子清晰。王灵官站在门口，一动不动。**玩家应该想进去，并且知道自己不该。**

### 蟠桃园（温柔）
> 全场唯一让人放松的地方。云洞开在正上方，阳光直射，暖。三千六百株桃树，同一棵树上花与果并存——粉白的花和红熟的果挂在一起，违反常识但没人觉得奇怪。前段果小青涩，走到后段变成紫纹缃核。花瓣缓慢飘落。园子四周一圈彩色云霓把它和外界隔开。土地和四类力士在远处忙碌。**玩家应该想在这里待着。**

### 瑶池（缺席）
> 铺设得齐齐整整，五彩描金桌、千花碧玉盆、九凤丹霞扆、八宝紫霓墩，一切就绪。琼香缭绕，瑞霭缤纷。长廊下造酒的仙官、盘糟的力士、运水的道人、烧火的童子还在忙。**却还未有仙来。** 席位牌上写着五方五老、三清四帝的名字，没有你的。**玩家应该感到一阵具体的、说不出口的东西。**

### 兜率宫（清冷）
> 最高，最远，最安静。三层高阁"朱陵丹台"上，老君与燃灯古佛讲道，众仙童侍立，声音很轻。丹房里八卦炉的火是全场唯一的高饱和暖色，从炉口向上冲出一道暖光柱，与稀薄的冷空气对比强烈。炉侧五个葫芦。绕到东南巽位，有风声。**玩家应该感到自己爬得很高，而且这里没什么人在乎他。**

### 广寒宫（例外）
> 全场唯一的冷色区，唯一的夜。银蓝色。桂树。捣药声有节奏地响着，是全场最好的空间音频。太阴星君和一群嫦娥在远处，不太理你。玉兔在捣药，会跟你抱怨。**玩家应该觉得走错了地方，然后不想走。**

### 斩妖台（无声）
> 空的。废弃的。台上一根降妖柱，柱身有砍痕。上方的云特别厚，光照不下来。没有 NPC，没有音乐，没有台词，什么都不会发生。**玩家应该在这里站一会儿，然后飞走。**

1. 须弥座标准分层（圭角—下枋—下枭—束腰—上枭—上枋）的权威文献出处。

3. 坤宁宫脊兽数（9 或 7），资料矛盾。
4. 明代举架系数相对清式的具体差异幅度，建议查《营造法式》与明代实例实测数据。

6. 「彩门」「玉阶」在天宫语境中查无原著出处，疑为影视改编产物。**本作弃用**，改称「朱门」「玉户」「丹墀」。
