## 主要依据

- 广州博物馆《广州地区出土的汉代船模》：东汉陶船 M5080 为首尾较狭、中段较宽、底平，设横梁、三舱、船首锚、船尾舵和舵楼；其他汉船模还显示桨、橹和重楼。
- 中国国家博物馆《绿釉陶楼》《汉代建筑明器研究》：东汉木构楼阁常见平座、勾栏、腰檐与斗栱；陶楼也常表现持弓卫士等防御含义。
- 《三国志·吴书·周瑜传》：火攻船“实以薪草，膏灌其中，裹以帷幕”，并预备走舸系于大船尾部。
- 湖北省档案信息网《赤壁》：赤壁位于长江南岸，隔江为北岸乌林；曹军退屯乌林，与孙刘联军隔江相峙。

## 建模注意

- `02` 的全帆状态更适合看桅杆和帆面关系；若做战斗状态，建议把帆卷起并降低帆布存在感。
- `03` 图中船首翘度偏强，正式模型可降低约 15%—25%，让长江内河船的浅吃水感更明确。
- `04` 的陶罐是视觉化处理；史料只明确“膏灌其中”，并未说明容器数量与摆放方式。
- `05` 的铁门环与金属包边可以做得更克制；核心应保留木构、夯土基础、木栅与灰瓦。
- 对 img2threejs，建议先裁掉空白并分别生成“船体（不含桨）”“桨组”“桅帆”“上层建筑”，最后在 Blender/Three.js 中装配，拓扑会更可控。
